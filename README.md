# 欢迎来到 TCraft WIKI

## 关于 T Craft

**T Craft 是面向 Minecraft Java 版玩家打造的高品质公益服生存服务器**

以稳定流畅、公平纯净、高安全、长期运营为核心理念，致力于为每一位方块爱好者打造安心、友好、长久的线上家园。
