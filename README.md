# 欢迎来到 Wiki

一个简洁的文档网站。

## 功能

- 全文搜索
- 图片缩放
- 代码复制
- 分页导航
- 深色模式

## 目录结构

```text
.
├── index.html              # 入口文件
├── README.md               # 首页文档
├── _sidebar.md             # 侧边栏配置
├── _coverpage.md           # 封面页
├── .nojekyll               # GitHub Pages 必需
├── guide/                  # 指南文档
│   ├── quickstart.md
│   ├── configuration.md
│   └── writing.md
└── examples/               # 示例文档
    ├── code.md
    └── images.md
```

## 开始

点击左侧导航栏浏览文档。
