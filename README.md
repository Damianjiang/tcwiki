# 欢迎来到 TCraft WIKI

## 关于 TCraft 服务器

**TCraft** 是一个面向 Minecraft Java 版玩家打造的高品质公益服生存服务器。我们以稳定流畅、公平纯净、高安全、长期运营为核心理念，致力于为每一位方块爱好者打造安心、友好、长久的线上家园。

服务器采用企业级硬件与优化架构，搭配全时段高防防护，有效抵御各类攻击与异常流量，实现24小时不间断稳定运行。

服务器主打**原版纯净生存**，保留MC核心玩法与全部特性，同时搭载便捷工具等轻量化插件，平衡原汁原味与游戏体验。无论是单人开荒、团队建造、红石生电，还是冒险探索、社区互动，都能找到属于自己的乐趣。
