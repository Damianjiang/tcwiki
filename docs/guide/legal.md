# 服务器法律合规条款

本服务器所有玩家的行为，均需遵守《民法典》《网络安全法》《个人信息保护法》等国家相关法律法规。

## 账号使用专属规范

::: warning ⚠️ 账号使用规范
- 账号使用权归注册人专属所有，**严禁出租、出借、转让、售卖账号**
- 严禁非法破解、入侵他人账号
- 账号被盗后，需及时联系服主冻结账号
:::

## 绝对禁止性行为

::: danger 🚫 严禁以下行为（违者封禁）
- 发布危害国家安全、泄露国家秘密等违法信息
- 实施 DDoS 攻击、非法爬取服务器数据等行为
- 使用物品挂、威胁服务器安全的挂端
:::

## 允许使用的辅助工具

矿透、光影、材质包等不影响服务器安全的客户端模组允许使用。
