# 白名单

本服是白名单制，**没通过白名单进不了服务器**。

## 申请步骤

1. 打开 [白名单申请页](http://xm.rainplay.cn:54623/)
2. 填**游戏内用户名**（必须和启动器里的 ID 一模一样，区分大小写）
3. 过验证码
4. 提交，等审核

::: warning 用户名必须完全一致
填错大小写或拼错，即使审核通过也进不去。填之前先看一眼启动器里的 ID。
:::

## 通过之后

审核一般 24 小时内完成。

通过后用这个地址进服：

```
tcraft.wdsjfwq.com
```

## 一直没通过

去 [问题反馈](/guide/feedback) 找服主，说明你的游戏 ID 和申请时间。
