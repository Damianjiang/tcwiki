# 白名单系统

::: tip 💡 白名单简介
本服采用白名单制，未加入白名单的玩家无法进入服务器。请按以下步骤申请加入白名单。
:::

## 白名单申请步骤

1. 访问白名单申请网页：[http://xm.rainplay.cn:54623/](http://xm.rainplay.cn:54623/)
2. 输入你的**游戏内用户名**（需与 Minecraft 启动器中填写的 ID 一致）
3. 完成**验证码**验证
4. 提交申请，等待管理员审核（如开启审核）

::: warning ⚠️ 申请注意事项
- 用户名必须与游戏内 ID **完全一致**（区分大小写），否则即使通过白名单也无法正常进服
- 审核通常在 24 小时内完成，请耐心等待
- 如长时间未通过，可通过 [反馈渠道](/guide/feedback) 联系服主
- 白名单通过后即可使用服务器地址 `tcraft.wdsjfwq.com` 进入游戏
:::
