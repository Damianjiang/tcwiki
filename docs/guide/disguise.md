# 伪装系统

::: tip 💡 功能简介
服务器提供**伪装**功能，你可以把自己变成各种生物或方块的外观。其他玩家看到的就是伪装后的样子，而你的实际角色、背包与能力完全不受影响。
:::

## 常用指令

| 指令 | 说明 |
|------|------|
| `/disguise <生物名>` | 伪装成指定生物，例如 `/disguise cow` |
| `/disguise player <玩家名>` | 伪装成某个玩家的外观 |
| `/disguise help` | 查看伪装指令与可选项帮助 |
| `/undisguise` | 取消伪装，恢复原貌 |

## 使用技巧

- 生物名使用英文，例如 `cow`（牛）、`sheep`（羊）、`zombie`（僵尸）、`creeper`（苦力怕）、`villager`（村民）等。
- 部分生物支持额外参数（如是否显示名字、是否携带装备），可用 `/disguise help` 查看完整说明。
- 伪装仅改变外观，不会改变你的血量、属性、权限或背包。
- 退出游戏或执行 `/undisguise` 后会立即恢复原本外观。

::: warning ⚠️ 使用须知
- 请文明使用伪装功能，不要利用伪装进行欺骗、诈骗或扰乱公共秩序。
- 伪装成其他玩家外观可能违反服务器规则，请谨慎使用，后果自负。
:::
