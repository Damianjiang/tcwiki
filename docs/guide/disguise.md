# 伪装

把自己变成别的生物或玩家的样子。别人看到的是伪装后的外观，你的血量、背包、能力都不变。

## 指令

| 指令 | 作用 |
|---|---|
| `/disguise <生物名>` | 变成指定生物，如 `/disguise cow` |
| `/disguise player <玩家名>` | 变成某个玩家的样子 |
| `/disguise help` | 看所有可选的生物名和参数 |
| `/undisguise` | 取消伪装 |

## 生物名用英文

常用的：

| 生物 | 写法 |
|---|---|
| 牛 | `cow` |
| 羊 | `sheep` |
| 僵尸 | `zombie` |
| 苦力怕 | `creeper` |
| 村民 | `villager` |

不确定的用 `/disguise help` 查。

部分生物支持额外参数（显示名字、带装备），也在 `help` 里。

## 什么时候恢复

- 输入 `/undisguise`
- 退出游戏再进来

::: warning 别用来骗人
伪装成其他玩家可能违反服务器规则。用伪装搞诈骗、扰乱秩序会被处罚。
:::
