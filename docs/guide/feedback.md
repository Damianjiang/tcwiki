# 问题反馈专属渠道

::: tip 💡 反馈简介
遇到服务器问题、功能异常、玩家纠纷等情况时，请通过以下渠道反馈。详细准确的描述有助于服主快速定位并处理问题。
:::

## 官方反馈网址

[https://tcraft.pages.dev](https://tcraft.pages.dev)

## 服主邮箱反馈

[orange38665@qq.com](mailto:orange38665@qq.com)

## 反馈要求

::: warning ⚠️ 反馈必须包含以下信息
提交问题时，**必须详细描述**以下内容，否则可能无法处理：

- **问题现象** - 具体出现了什么问题
- **发生时间** - 问题出现的具体时间
- **操作步骤** - 复现问题的具体操作
- **游戏账号 ID** - 你的游戏内用户名
:::

服主将在 24 小时内对反馈问题进行回复和处理。

::: tip 💡 反馈建议
- 如遇游戏内 BUG，建议附上截图或录屏
- 如遇玩家违规，请提供违规玩家的 ID 与违规证据
- 描述越详细，问题解决越快
:::
