# 论坛

服务器官方论坛，发公告、闲聊、问问题、发攻略。**账号和游戏账号是同一个**，在游戏里设个论坛密码就能用。

## 地址

官网 → 功能区 → 论坛，或直接开：

```
http://xm.rainplay.cn:54623/forum
```

登录一次会记住，下次不用再登。

## 第一次用：在游戏里设密码

```
/t forum 你的论坛密码
```

例：`/t forum Tc2024#abc`

然后打开论坛，用户名填**你的游戏 ID**，密码填刚才设的。

::: warning 论坛密码和游戏密码是两套
互不影响。两个都别忘，**忘了都只能找服主重置**。

同一条 `/t forum` 命令既能首次设置，也能改密码。
:::

## 板块

| 板块 | 发什么 |
|---|---|
| 📢 公告 | 服务器公告（管理员发） |
| 💬 闲聊 | 随便聊 |
| ❓ 问答 | 有问题在这问 |
| 🎮 游戏攻略 | 技巧、心得 |

## 发帖和评论

**发帖**：登录 → 「发布新帖」→ 选板块 → 填标题和内容 → 发布

**评论**：进任意帖子 → 拉到底部评论框 → 输入 → 发表

## 管理员

登录后右上角有「管理」按钮：

- **用户** —— 封禁/解封、设为管理员
- **板块** —— 新建/修改板块、设权限
- **帖子** —— 删除、置顶、锁定
- **设置** —— 站名、字数限制

## 常见问题

**忘了论坛密码？** 找服主重置。

**账号被封了？** 找管理员申诉。

**看不到「发布新帖」？** 三种可能：没登录、账号被封、该板块只有管理员能发。
