# TCraft 论坛系统使用教程

## 访问论坛

论坛地址：官网 → 功能区 → 论坛系统，或直接访问 `http://xm.rainplay.cn:54623/forum`

登录后会自动保存登录状态，下次访问无需重新登录。

## 账号注册与登录

### 游戏内注册账号

1. 进入游戏
2. 输入命令：`/tcraft forum 密码`
3. 示例：`/tcraft forum mypassword123`
4. 注册成功后，打开论坛，使用玩家名和注册的密码登录

### 登录说明

论坛用户名为你的游戏内玩家名，密码为游戏内注册时设置的密码。

## 浏览帖子

首页显示所有板块：

- 📢 公告 - 服务器公告和重要通知
- 💬 闲聊 - 自由聊天板块
- ❓ 问答 - 有什么问题可以在这里提问
- 🎮 游戏攻略 - 分享游戏技巧和攻略

## 发布帖子

1. 登录后，点击「发布新帖」按钮
2. 选择要发布的板块
3. 填写帖子标题和内容
4. 点击「发布」

## 评论互动

1. 登录后进入任意帖子
2. 在帖子下方找到评论框
3. 输入评论内容，点击「发表评论」

## 修改密码

密码修改需要在游戏内使用命令：`/tcraft forum 新密码`

## 管理员功能

管理员登录后，右上角会显示「管理」按钮，可进行以下操作：

- **用户管理：** 查看所有用户、封禁/解封用户、设为管理员
- **板块管理：** 创建新板块、修改板块、设置权限
- **帖子管理：** 删除帖子、置顶/锁定帖子
- **网站设置：** 配置网站名称、字数限制等

## 常见问题

**Q: 忘记密码怎么办？**

A: 联系服务器管理员重置密码

**Q: 账号被封禁了怎么办？**

A: 联系服务器管理员申诉

**Q: 为什么看不到「发布新帖」按钮？**

A: 可能是因为没有登录、账号被封禁、或该板块仅限管理员发帖
