# 领地系统帮助

::: warning ⚠️ 重要：领地自动清理规则
**玩家超过 256 天未登录游戏，其名下所有领地将被自动删除，且无法恢复。**

请务必定期登录服务器，以免长期未登录导致领地丢失。如果你需要长期离开，建议提前将领地转让给可信的好友保管。
:::

## 基础说明

- 领地最大：128×128（高度不限）
- 圈地工具：木锄头
- 查询工具：线（STRING）
- 进入 / 离开领地会在动作条提示

## 创建领地（2 种方法）

### 方法 1：手动圈地（推荐，最大 128×128）

1. 拿木锄头，左键点领地第一个角
2. 拿木锄头，右键点领地对角
3. 输入指令创建：`/dom create 领地名`
4. 示例：`/dom create 我的家`

### 方法 2：自动圆形领地

1. 站在领地中心，输入：`/dom auto 领地名 半径`
2. 示例：`/dom auto 农场 20` → 直径 40×40

## 查看与管理领地

- `/dom list` - 查看自己所有领地
- `/dom` - 打开领地 GUI（可视化管理，推荐）
- 可进行：加成员、开关权限、传送、删除领地
- 拿线点击领地 - 查询他人领地（所有者、大小、成员、权限）
- `/dom tp 领地名` - 领地传送
- `/dom remove 领地名` - 删除领地

## 领地权限设置

### 常用权限

| 权限 | 说明 | 默认 |
|------|------|------|
| build | 建造 / 破坏 | 关闭 |
| move | 进入领地 | 开启 |
| interact | 开门 / 按钮 | 关闭 |
| container | 开箱子 | 关闭 |
| pvp | 玩家对战 | 关闭 |

**指令格式：** `/dom set 领地名 权限 true/false`

**示例：** `/dom set 我的家 build false`

### 添加成员

- `/dom addmember 领地名 玩家名` - 添加成员
- `/dom removemember 领地名 玩家名` - 移除成员

## 常见问题

**Q：为什么不能圈地？**

A：出生点附近10格内禁止圈地 / 领地超过128×128上限 / 没有领地创建权限

**Q：怎么给好友全部权限？**

A：在 GUI 中把好友设为管理员，或用指令：`/dom setowner 领地名 玩家名`

**Q：领地能升级扩大吗？**

A：可以，用箭重新选更大范围，输入：`/dom resize 领地名`
