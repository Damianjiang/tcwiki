# 箱子、门、熔炉上锁

给你的箱子、熔炉、门上锁，只有你和你信任的人能用。

## 上锁

- **自动**：放箱子、熔炉、门的时候自动归你所有并上锁
- **手动**：对着已有的方块 **Shift + 右键**
- **指令**：`/lock`（锁你正在看的方块）

上锁后方块上会出现锁的标识。

## 指令

| 指令 | 作用 |
|---|---|
| `/lock` | 锁住正在看的方块 |
| `/unlock` | 解锁 |
| `/lock info` | 看这个方块归谁、授权了谁 |
| `/lock trust add <玩家>` | 允许某人使用 |
| `/lock trust remove <玩家>` | 取消某人的权限 |
| `/lock password <密码>` | 设密码锁 |

## 几个注意点

- 拆掉方块锁自动解除，**重新放上去要重新锁**
- 和队友共用仓库，用 `/lock trust add` 把人加进来
- 别人拆你的锁方块前会先检查权限

::: warning 别把自己锁外面
共享仓库长期不用时，确认授权列表里有队友，不然他们打不开。
:::
