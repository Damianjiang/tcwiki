# 容器与方块锁

::: tip 💡 功能简介
担心箱子、门被别人乱开？服务器提供**方块锁**功能，你可以给箱子、门、熔炉等方块上锁，只有你和信任的好友才能使用，保护你的财产安全。
:::

## 上锁方式

- **自动上锁**：放置箱子、熔炉、门等可锁方块时，会自动归属并上锁给你本人。
- **手动上锁**：对着已存在的方块 **Shift + 右键** 即可上锁。
- 上锁后会在方块上生成一把"锁"标识，未授权的玩家无法打开或使用。

## 常用指令

| 指令 | 说明 |
|------|------|
| `/lock` | 锁定你正在看向的方块 |
| `/unlock` | 解除当前方块的锁 |
| `/lock info` | 查看当前方块的锁信息（所有者、授权人） |
| `/lock trust add <玩家名>` | 添加可信玩家，允许其使用 |
| `/lock trust remove <玩家名>` | 移除已授权的玩家 |
| `/lock password <密码>` | 设置密码锁（输入密码才能打开） |

## 使用建议

- 公共建筑、资源共享点时，可用 `/lock trust add` 把队友加为可信用户，方便协作。
- 长期不玩的共享仓库，建议设置密码或明确授权，避免误锁导致队友无法取物。
- 拆除方块会自动解除锁，无需手动解锁；重新放置后需重新上锁。

::: warning ⚠️ 重要提醒
- 上锁方块被他人破坏前会先校验权限，请妥善保管你的锁授权列表。
- 锁信息记录在方块上，拆除后重新放置需重新上锁。
:::
