# @提及与私信

两种叫人方式：**@** 是在公屏点名，**私信**是只说给一个人听。

## @提及

在聊天里打 `@玩家名`，所有人还是能看到这条消息，但被 @ 的人会额外收到黄色提醒 + 提示音。

| 写法 | 说明 |
|---|---|
| `@Steve` | 英文 @ |
| `＠Steve` | 中文 ＠ 也行 |
| `@Steve @Alex` | 一条消息里 @ 多个人 |
| 打 `@` 后按 Tab | 自动补全玩家名 |

例：`大家好 @Steve 来玩吧！`

::: warning @ 有次数限制
**10 秒内最多 3 次**，一条消息最多 @ 5 人。防止刷屏。
:::

## 私信

```
/t tell <玩家名> <内容>
```

例：`/t tell Steve 你在哪，我过来`

只有对方能看到，别人看不到。

打 `/t tell ` 之后按 **Tab** 会列出在线玩家。

## 两者区别

| | @提及 | 私信 |
|---|---|---|
| 谁能看到 | **所有人** | 只有对方 |
| 能 @ 几个 | 多个 | 一个 |
| 怎么发 | 聊天框直接打 | `/t tell` 指令 |
| 离线能收吗 | 不能 | 不能 |

## 注意

- **只能发给在线的人**，离线收不到
- **不能给自己发**
- **聊天记录不会保存**，关掉窗口就没了，重要内容自己截图
