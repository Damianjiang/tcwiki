# @提及功能与私信命令

::: tip 💡 功能简介
TCraft 提供两种私密沟通方式：聊天中的 **@提及** 用于在公共频道中点名提醒特定玩家；**`/tcraft tell` 私信命令** 用于与单个在线玩家进行一对一私聊。两者均只在玩家在线时生效。
:::

## @提及功能

在聊天中使用 `@玩家名` 提及在线玩家，聊天消息正常显示给所有人，被@的玩家会收到专属提醒。

| 操作 | 说明 |
|------|------|
| `@玩家名` | 英文@提及玩家 |
| `＠玩家名` | 中文＠提及玩家 |
| `@玩家名1 @玩家名2` | 同时提及多个玩家 |
| 输入 `@` 后按 Tab | 自动补全玩家名称 |

**示例：** 输入 `大家好 @Steve 来玩吧！`

• 所有在线玩家正常看到聊天消息

• 被@的玩家收到黄色提醒消息

• 被@的玩家听到提示音

## /tcraft tell 私信命令

向指定在线玩家发送私信，只有对方能看到，其他玩家看不到。

**命令格式：** `/tcraft tell <玩家名> <内容>`

| 参数 | 说明 |
|------|------|
| `<玩家名>` | 目标玩家的游戏名称 |
| `<内容>` | 要发送的私信内容（支持空格） |

**示例：** `/tcraft tell Steve 你好，一起来玩吧！`

接收方会看到私信内容并听到提示音

## 功能对比

| 功能 | @提及 | /tcraft tell |
|------|--------|--------------|
| 聊天可见范围 | 所有在线玩家 | 仅目标玩家 |
| 专属提醒 | 仅被@者收到 | 接收方收到 |
| 使用方式 | 聊天中输入 | 命令方式 |
| Tab补全 | ✅ 支持 | ✅ 支持 |
| 提示音 | 被@者收到 | 接收方收到 |
| 支持多人 | ✅ 可同时@多人 | ❌ 只能发给一人 |
| 离线支持 | ❌ 仅在线玩家 | ❌ 仅在线玩家 |

## 注意事项

::: warning ⚠️ 使用须知
- **只能发送给在线玩家**：离线玩家无法接收 @提及 或私信
- **不能给自己发送私信**：系统会拦截自己发给自己的消息
- **输入 `/tcraft tell ` 后按 Tab** 会显示当前在线玩家列表，方便快速选择
- **@提及和私信均不记录历史**：关闭聊天窗口后内容将不再可见，重要信息请另行保存
:::
