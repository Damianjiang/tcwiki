# 个性化昵称设置

支持彩色样式，含专属编辑器。

## 在线样式编辑器

**编辑器网址：** [https://tcraft.pages.dev/hexnicks](https://tcraft.pages.dev/hexnicks)

## 设置自定义昵称指令

`/nick 昵称/样式代码`

**普通昵称示例：** `/nick TCraft_玩家01`

## 恢复原游戏ID指令

`/nick off`

## 昵称设置重要规范

::: danger ⚠️ 违规封禁警告
设置昵称须遵守以下规范，**违规经提醒未修改的，将直接封禁处理**：

- 昵称长度需在 2-16 个字符之间
- 严禁使用侮辱性、广告性、违规政治相关词汇
- 严禁使用其他玩家的 ID、模仿管理员名称
:::
