# TCraft 服务器规则

> 版本：V2.1　最后更新：2026-09-01

::: danger ⚠️ 进服必读
本规则为服务器唯一最高准则，所有群规、临时规定均以本文件为准。凡进入服务器的玩家，即视为已阅读并同意本规则全部条款，并服从管理人员依据本规则作出的判定。
:::

---

## 第一章 总则

### 1.1 规则效力

1. 本规则适用于服务器全部域名及子域名下所有 Minecraft Java 版服务器（含官方服务器列表内全部群组服），适用范围见附录 A。
2. 本规则可随时更新增补，更新后即时生效，不另行单独通知。
3. 任何玩家不得以"不知情"为由抗辩或请求免除处罚。

### 1.2 术语定义

| 术语 | 定义 |
|------|------|
| 警告 | 口头或文字提醒，记录在案，不产生封禁 |
| 禁言 | 禁止发言一定时长 |
| 封禁 | 禁止进入服务器一定时长 |
| 永久封禁 | 禁止进入服务器，不设解除期限 |
| 累犯 | 同一玩家在同一规则条款下第二次及以上的违规 |
| 跑图 | 一次性大范围探索、加载大量新区块的行为（详见 3.1.5） |
| 卡服 | 通过人为操作或机械装置造成服务器卡顿、TPS 显著下降或崩溃 |
| 高危设备 | 高负载、可致服务器崩溃的大型机械装置（详见第四章） |
| 报备 | 向管理员登记设备的坐标、用途与运行时长，经确认后方可运行 |

### 1.3 判定原则

1. 一切违规判定以服务器性能数据、运行日志、崩溃记录、建筑破坏证据为准。
2. 违规判定与是否使用作弊无关，仅针对损害服务器稳定、公共环境及他人游戏体验的行为。
3. 本章节未列明的行为，如实质造成服务器卡顿、负载异常、区块崩溃或公共损失，由管理团队依第六条的处罚标准裁定。

## 第二章 作弊管理

### 2.1 允许的辅助作弊（不违规、不追责）

以下**纯辅助类**作弊客户端、模组、功能在本服允许使用：

1. **信息辅助**：透视、矿透、实体追踪、坐标显示、HUD 信息显示。
   - 示例：找矿物、找建筑、看实体位置、显示耐久等，均允许。
2. **移动辅助**：个人飞行（客户端 / 模组飞行）、加速。
   - 允许：自己飞行移动、赶路。
   - 禁止：利用飞行 / 加速**一次性大范围探索新区块**（跑图，见 3.1.5）。
3. **操作辅助**：自动挖矿、自动钓鱼、自动收集、连点（正常操作用途）。
   - 允许：自动挖矿、自动钓鱼、自动捡物、连点挖方块。
   - 禁止：用连点**高频触发拉杆、按钮、压力板等红石**造成服务器卡顿（见 3.1.6）。

> 判断口诀：**只要能帮助你自己，不伤害服务器、不伤害别人，就允许。**

### 2.2 禁止的作弊类型

1. **PVP 战斗类**：杀戮光环、自瞄、距离修改（reach）、PVP 自动回避 / 自动反击。在 PVP 场景使用视为恶意 PVP，依 3.3.1 处罚；在 PVE 与单人生存场景使用不受限制。
   - 常见疑问：
   - ❌ 违规：在打架、守尸、袭击他人时开杀戮光环、自瞄、reach。
   - ✅ 允许：在 PVE（打怪、刷怪塔）或单人生存使用战斗辅助，不影响他人。
   - ❓ 什么时候算 PVP 场景？只要攻击对象是**真实玩家**，就按 PVP 场景处理。
2. **物品 / 经济类**：物品复制、刷物、give、背包修改、属性 / 附魔修改。此行为损害经济体系与他人权益，全面禁止，依 3.2.3 或 3.1.3 处罚。
   - 常见疑问：
   - ❌ 违规：复制钻石 / 刷物品、用模组改背包里的东西、给自己改附魔 / 属性。
   - ✅ 允许：正常游戏获取物品、正常交易。
   - ❓ 捡到别人复制出来的物品怎么办？不拿、不交易，截图举报给管理。
3. **破坏类**：利用穿墙移动进入他人领地盗窃、破坏建筑。穿墙移动本身允许，但利用穿墙实施盗窃、破坏依 3.2.1、3.1.1 处罚。
   - 常见疑问：
   - ❌ 违规：穿墙进别人家偷箱子、穿墙拆别人建筑。
   - ✅ 允许：穿墙主要用于赶路、找路、自己家里进出。
   - ❓ 穿墙进去后"只看不拿"行不行？不行。未经同意进入他人领地窥探即可能构成骚扰，请先征得同意。

### 2.3 其他说明

红石飞行器、轰炸机等机械飞行属高危设备，须按第四章完成报备后方可建造、运行。
- ❌ 违规：不报备直接造飞行器 / 轰炸机轰炸别人建筑或自己家。
- ✅ 允许：按第四章报备通过后正常使用。
- ❓ 想玩机械飞行？先按第四章流程报备，通过后再开机。

## 第三章 禁止行为与处罚

> 本章各条处罚梯度为：**首次 → 累犯 → 情节严重**。档位定义见第六章。

::: danger 🔴 重点打击
**损害他人财产（恶意破坏、盗窃、物品作弊、未经允许修改他人建筑）** 为侵害其他玩家权益的严重行为，本服**零容忍、从严从重处罚**，不适用口头警告起步。相关条款见 3.1.1、3.2.1–3.2.3。
:::

### 3.1 损害服务器稳定类

#### 3.1.1 恶意破坏他人财产

1. 定义：恶意破坏他人建筑、盗窃后拆毁他人设施、大范围毁图、恶意炸服、恶意清空区域。
2. 定性：破坏他人财产为侵害其他玩家权益的严重行为，本服重点打击、从严从重处罚。
3. 处罚：首次封禁 15 天并清除违规建筑数据；累犯或情节特别严重者永久封禁。
4. 常见疑问：
   - ❌ 违规：用 TNT / 火焰弹 / 末影水晶炸别人房子、拆别人整座基地、把别人的农田 / 红石装置全挖了、把别人辛苦建的区域毁掉。
   - ✅ 允许：拆自己建的建筑、主人明确同意你拆的、无主废弃建筑经管理确认后处理。
   - ❓ 想拆一栋"废弃"建筑？先 @ 管理确认无主，管理同意后再动手，否则按破坏他人财产处理。
   - ❓ 不小心破坏了怎么办？第一时间主动找管理说明、恢复原状、取得主人谅解，可酌情从轻；隐瞒不报、拒不恢复从重。

#### 3.1.2 触发服务器崩溃

1. 定义：任何导致服务器看门狗崩溃、强制关服的行为。
2. 处罚：无意触发封禁 7 天并清理违规数据；故意触发或累犯永久封禁。
3. 常见疑问：
   - ❌ 违规：故意制造崩溃（如批量实体、大型爆炸连锁、恶意利用漏洞刷崩）、明知会崩仍反复尝试。
   - ✅ 允许：正常游玩、正常建造，偶发故障由管理排查处理。
   - ❓ 怎么算"故意"？有预谋、反复尝试、收到提醒仍继续 = 故意。吃不准先问管理。

#### 3.1.3 造成服务器持续卡顿

1. 定义：通过人为操作或机械装置造成服务器大范围、持续性卡顿或 TPS 暴跌。
2. 处罚：封禁 3–7 天，并强制清理相关设备。
3. 常见疑问：
   - ❌ 违规：挂一堆高频红石不关、实体堆成山、大量掉落物不清理、同时开太多大型机器。
   - ✅ 允许：正常规模的红石、机器和养殖，不影响服务器流畅度。
   - ❓ 管理提醒"你机器卡服了"怎么办？立即停机 / 拆除，配合处理可从轻处罚；拒不停机从重。

#### 3.1.4 制造、运行卡服设备

1. 定义：制造、运行卡服机、禁人书、禁人塔、区块锁死装置等直接拖垮服务器性能的设备。
2. 处罚：强制拆除，首次封禁 7 天；累犯永久封禁。
3. 说明：刷物机、刷沙机、刷线机**不属于**本款所称卡服设备，按第四章报备制度管理；仅当其造成服务器卡顿、TPS 暴跌时，依本款从重处理。
4. 常见疑问：
   - ❌ 违规：禁人书（无限把玩家踢出服务器的书）、禁人塔、区块锁死（让他人无法进入的方块围堵）、高频红石风暴。
   - ✅ 允许：小型刷物机、刷沙机、刷线机（按第四章报备或豁免）。
   - ❓ 搞不清？直接问管理，报备后再开机，就不会被误伤。

#### 3.1.5 禁止跑图探图

1. 定义：利用鞘翅、高速机械、活塞推动载具、模组传送、加速 / 飞行等方式，一次性大范围探索并加载大量新区块的行为。
2. 理由：跑图导致地图无限膨胀、区块过度加载、服务器负载飙升。
3. 范围：正常建造、建筑与家附近活动不受影响。
4. 处罚：跑图造成区块大量加载或服务器卡顿的，清理加载区块，首次警告或封禁 3 天；累犯封禁 3–7 天。
5. 常见疑问：
   - ❌ 违规：用鞘翅 / 飞行一次性飞出数万格探索新地形；用高速飞行器穿越地图找新群系；开新版本号"探图"加载大量未生成区块。
   - ✅ 允许：在家附近几百格内活动、正常去自己建筑、去已建成的公共区域。
   - ❓ 怎么算"大范围"？判断标准是**是否一次性加载了大量"新生成的区块"**。不是看距离，而是看有没有大量生成新区块。吃不准就先问管理。

#### 3.1.6 高频连点卡服

1. 定义：对拉杆、按钮、压力板进行极速连点、高频右键操作，造成服务器卡顿。
2. 区分：连点用于挖矿、钓鱼、放置等正常操作允许；仅高频触发红石、拉杆、按钮致服务器卡顿时违规。
3. 判断标准：是否造成服务器卡顿或 TPS 显著下降。
4. 处罚：首次警告并禁言 1 天；情节严重封禁 3 天。
5. 常见疑问：
   - ✅ 允许：连点挖方块、连点钓鱼、连点放方块。
   - ❌ 违规：把连点器对着拉杆 / 按钮 / 压力板猛点，把红石刷成高频，导致服务器卡。
   - ❓ 简单记：**对"开关类"东西疯狂连点 = 违规；对"方块类"东西连点 = 允许。**

#### 3.1.7 末地与生物负载

| 条款 | 行为 | 处罚 |
|------|------|------|
| 3.1.7.1 | 末地维度种植大量蘑菇、堆载蘑菇区块 | 警告并清空违规区块；累犯封禁 3 天 |
| 3.1.7.2 | 末地祭坛范围部署杀凋机、高频凋灵刷新装置 | 拆除装置，首次封禁 3 天；累犯封禁 7 天 |
| 3.1.7.3 | 刷怪笼内部 / 周边养鸡，致实体堆积 | 清空实体，警告；累犯封禁 1 天 |
| 3.1.7.4 | 大规模批量养殖、超高实体堆叠致区块过载 | 清理实体，警告；累犯封禁 1–3 天 |
| 3.1.7.5 | 远距离搬运、批量放置蜂巢 / 蜂箱致区块实体常驻过载 | 拆除装置，警告；累犯封禁 1 天 |

> 以上条款判断标准统一为：**是否造成服务器卡顿、TPS 下降或区块过载**。正常规模的养殖、刷怪、养蜂不影响服务器流畅度即可放心玩；一旦卡服，先停机再处理，配合从轻。

### 3.2 损害他人权益类

#### 3.2.1 盗窃

1. 定义：未经许可拿走他人物品、箱子、建筑材料。
2. 定性：盗窃为侵害其他玩家权益的严重行为，本服重点打击、从严从重处罚。
3. 处罚：首次警告并限期归还、记录在案；拒不归还未造成重大损失的封禁 7 天，造成重大损失的封禁 15 天；累犯或涉及批量盗窃永久封禁。
4. 常见疑问：
   - ❌ 违规：拿别人箱子里东西、挖别人农田作物、顺走别人建筑的材料、偷别人箱子 / 潜影盒。
   - ✅ 允许：别人明确说"可以拿"、公共储物处（无主标识）的物品。
   - ❓ 不确定是不是别人的？**默认是别人的**。没主标识的东西也别乱拿，被举报就算违规。

#### 3.2.2 未经允许修改他人建筑

1. 定义：未经建筑所有者许可，擅自改动、移动、拆除、替换、占用他人建造的建筑、设施、红石装置、装饰等内容。
2. 适用范围：本款适用于服务器全部区域。**无论建筑是否设置领地、圈地、箱子锁等保护措施，本款一律生效**。
3. 区分：直接破坏他人建筑依 3.1.1 处罚；本款针对改动、修改、占用他人劳动成果但尚未达到毁坏程度的行为。
4. 处罚：首次警告并限期恢复原状、记录在案；拒不恢复或造成损失的封禁 3–7 天；故意大面积改动或累犯封禁 15 天。
5. 常见疑问：
   - ❌ 违规：没问主人就改别人房子的墙、把别人红石装置拆了重摆、占别人盖好的建筑当自己家、未经同意把别人装饰替换掉。**即使没设领地，也一样违规。**
   - ✅ 允许：主人明确同意、主人邀请你一起建造、公共设施（车站、仓库等无主公共建筑）的维护。
   - ❓ 想帮忙 / 想借用？**先问主人**。问一句"我能动这个吗"就没事了。
   - ❓ "我把家搬进没设领地的空房"行不行？不行。房屋有主人就算他的，未设领地不等于无主。想入住先联系房主或找管理确认。

#### 3.2.3 物品作弊

1. 定义：使用物品复制、刷物、give、背包修改等获取物品。
2. 处罚：清除违规所得，首次封禁 7 天；累犯或涉及倒卖牟利永久封禁。
3. 常见疑问：
   - ❌ 违规：复制钻石块 / 下界合金、用插件 / 模组刷物品、修改自己背包里的物品、给装备改属性附魔。
   - ✅ 允许：正常获取、正常交易、正常建造。
   - ❓ 怎么区分"刷物"和"刷怪塔"？刷怪塔是正常游戏机制，产出由服务器记录；刷物是直接凭空 / 复制产生物品，属于作弊。
   - ❓ 收下别人"送"的复制物品行不行？只要明知是作弊产物，收下 / 使用同样违规。

#### 3.2.4 恶意举报

1. 定义：恶意举报、诬告正常玩家、恶意干扰管理工作。
2. 处罚：警告并禁言 1–3 天。
3. 常见疑问：
   - ❌ 违规：没证据就乱举报别人"破坏 / 作弊"、编造事实诬告、反复刷举报骚扰管理。
   - ✅ 允许：有截图 / 录屏 / 明确事实依据的正常举报。
   - ❓ 举报要带什么？尽量带时间、地点、截图 / 录屏证据。证据不足的举报不会被处理，但也不会处罚举报人（除非是恶意诬告）。

### 3.3 恶意 PVP 类

#### 3.3.1 恶意 PVP

1. 定义：以下行为构成恶意 PVP：
   - 守尸、堵出生点 / 传送点连续击杀；
   - 对无反抗意愿玩家追杀骚扰；
   - 强制他人进入 PVP 状态；
   - 利用 PVP 抢夺他人物品；
   - 在 PVP 中使用杀戮光环、自瞄等战斗作弊模块（见 2.2.1）。
2. 区分：双方明确同意的切磋、约定 PVP 不构成违规。
3. 判定：恶意 PVP 与是否作弊无关，仅以是否单方面强加、是否骚扰他人为准。
4. 处罚：首次警告并封禁 1 天；情节严重封禁 3–7 天，并归还被抢装备。
5. 常见疑问：
   - ❌ 违规：堵传送点 / 出生点连续杀新人；别人跑了还追着杀；别人说"不打"你还打；组队围殴落单玩家并抢装备；在 PVP 里开杀戮光环 / 自瞄。
   - ✅ 允许：双方约好的切磋（打之前先说好）、对方明确同意 PVP、守护自己领地反击入侵者（但不得跨传送点追杀）。
   - ❓ 对方抢你装备怎么办？截图 / 录屏 → 举报给管理，管理会归还装备并按 3.3.1 处理。**不要自己动手报仇**，报仇会连你也一起违规。

### 3.4 账号与信息类

#### 3.4.1 注册小号

1. 定义：同一玩家注册、使用一个以上账号；或利用小号入驻、违规顶号。
2. 处罚：大号封禁 10 天，小号全部删除。
3. 加重：利用新账号逃避封禁（绕封）情节严重的，大小号同步永久封禁。

## 第四章 高危设备报备制度

### 4.1 需报备的设备

以下设备在建造、开机、试运行前必须向管理员报备，登记坐标、用途与运行时长：

1. 飞行器轰炸机、高速弹射飞行器、世界吞噬机（世吞）；
2. 大型轨道炮、TNT 大炮、连发炮组、远程爆破装置；
3. 大型高频红石阵列、大规模脉冲红石设备；
4. 大型全自动刷怪机、刷物机、刷沙机、刷图机、刷线机、掉落物堆积机器。

### 4.2 报备流程

1. 私信管理员提交设备类型、坐标、用途与计划运行时长。
2. 管理员确认后方可运行。未经确认运行即视为私自运行。
3. 常见疑问：
   - ❌ 违规：不报备直接建大型机器、报备了但超额运行（报"运行 1 小时"实际挂一晚上）、报备内容与实际不符。
   - ✅ 合规：先问后建、按批准的时间和规模运行、机器改动后重新报备。
   - ❓ 嫌麻烦？**小型机器根本不用报备**（见 4.3）。只有大型、高频、高危设备才需要。

### 4.3 小型设备豁免

1. 单机、低频、低负载的小型刷物机 / 刷沙机 / 刷线机允许自由建造使用，无需报备。
2. 豁免标准：单台机器、不阵列化、不高频、不堆叠掉落物。
3. 设备规模扩大（阵列化、高频、堆积掉落物）即视为大型设备，须报备。
4. 任何刷物机造成卡顿、TPS 暴跌的，立即停机拆除，拒不执行依 3.1.3 处罚。
5. 常见疑问：
   - ✅ 不用报备：一台小型全自动甘蔗机、一台小型刷石机、一台单组刷怪塔、自己家的小型刷线机。
   - ❌ 要报备：把刷物机连一排做成阵列、高频刷怪塔、掉落物堆成山的机器、TNT 大炮、飞行器轰炸机。
   - ❓ 怎么算"大型"？**机器越多越危险**。自己拿不准，就把截图发给管理问一句，10 秒的事。

### 4.4 处罚

1. 报备通过：可合法使用。
2. 私自建造运行：封禁 3 天并强制拆除设备。
3. 报备设备运行中出现卡顿、掉 TPS、负载异常的，须立即停机；拒不停机依 3.1.3 从重处罚。

## 第五章 服务器日常行为规范

1. **区块加载**：禁止长时间挂机占用加载器、恶意常驻区块加载造成持续负载。违规造成卡顿的，依第六章处罚（警告起步）。

   - ❌ 违规：故意站在加载器里 / 用机器常驻加载大量区块让服务器一直掉 TPS。

   - ✅ 允许：做好防实体措施的底层挂机（如封好空间、清理蝙蝠）。
   - ❌ 违规：用盔甲架卡死挂机、挂机不管导致实体堆积卡服。
3. **指令使用**：禁止滥用高频指令、重复刷屏拖垮服务器主线程。违规依第六章处罚（警告 / 禁言起步）。
   - ✅ 允许：正常使用指令、偶尔查询 / 传送。
   - ❌ 违规：用脚本 / 连点反复刷同一条指令、高频传送刷屏。
4. **言论规范**：禁止散播消极言论、煽动退服、抹黑服务器、挑动玩家对立。视情节警告或禁言。

   - ❌ 违规：带节奏劝人退服、造谣抹黑服务器、挑拨玩家吵架。
5. **管理配合**：尊重管理团队执法，禁止挑衅、对线、辱骂管理员。视情节警告或禁言。
