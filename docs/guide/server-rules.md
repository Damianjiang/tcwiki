# TCraft服务器规则

::: danger ⚠️ 进服必读 - 最高准则
本规则为服务器**唯一最高准则**，所有群规、临时规定均以此文件为准。**所有进入服务器的玩家，即默认同意本规则全部条款，无条件服从管理判定。** 规则可随时更新增补，更新后即时生效，不接受"不知情"辩解。
:::

::: tip 💡 规则核心理念
本服**全面开放所有作弊功能**（外挂、透视、飞行等均不违规），仅严控**毁服、卡服、熊破坏**行为。所有违规判定**与是否作弊无关**，仅针对损害服务器与公共环境的行为追责。
:::

## 一、适用范围

本规则适用于 `xm.rainplay.cn`、`tcraft.pages.dev`、`tcwiki.pages.dev`、`tcwiki.github.io`、`*.tcraft.dpdns.org` 所有域名及子域名下全部 Minecraft Java Edition 服务器（官方服务器列表内所有群组服）。

**所有进入服务器的玩家，即默认同意本规则全部条款，无条件服从管理判定。**

## 二、核心总纲（最重要）

1. **本服全面开放所有作弊功能** 本服**不限制任何外挂、作弊客户端、作弊模组、作弊功能**。 透视、**个人飞行（客户端/模组飞行）**、加速、杀戮光环、自瞄、穿墙、距离修改、矿透、自动挖矿、自动钓鱼、连点、物品作弊、实体追踪、背包修改等**全部个人作弊行为、作弊模块均完全允许、不予封禁、不予处罚**。注意：**红石飞行器、轰炸机等机械飞行属高危设备，须按第四条报备后方可建造运行**。
    
2. **唯一红线：禁止损害服务器与公共环境** 所有违规判定**与是否作弊无关**。 仅以下行为属于违规：**恶意熊破坏、盗窃他人物品、制造卡服机器、触发服务器卡顿 / 过载 / 看门狗崩溃、私自建造高危毁服机械、违规堆叠生物、滥用机制拖垮服务器性能**。
    
3. 管理判定原则 一切以**服务器性能数据、卡顿日志、崩溃记录、建筑破坏证据**为准，不针对个人作弊行为追责，只针对毁服、卡服、熊行为追责。
    

## 三、严格禁止事项（违者直接处罚・附精准处罚结果）

1. 🚫 **恶意熊破坏、恶意炸服、大面积毁图、破坏他人建筑** 处罚：**永久封禁账号 + 清除全部违规建筑数据**
    
2. 🚫 **盗窃他人物品、箱子、建筑材料** 处罚：**归还被盗物品，拒不归还按情节轻重处以封禁**
    
3. 🚫 **任何行为触发服务器看门狗崩溃、强制关服** 处罚：**永久踢出并拉黑服务器，永久封禁**
    
4. 🚫 **人为操作、机械装置造成服务器大范围、持续性卡顿、TPS 暴跌** 处罚：**服务器小黑屋封禁 7 天，强制清理卡服设备**
    
5. 🚫 **末地维度种植大量蘑菇、堆载蘑菇区块** 处罚：**封禁 3 天 + 清空违规区块**

7. 🚫 **刷怪笼内部 / 周边养鸡、大量堆叠家禽造成实体堆积** 处罚：**清空实体 + 封禁 1 天**
    
8. 🚫 **大规模批量养殖生物、超高实体堆叠（牛马猪鸡猫等）造成区块过载** 处罚：**全员实体空 + 违规玩家封禁 3 天**

15. 🚫 **宣传外服、引流外服、搬运本服素材做外服宣传** 处罚：**永久禁言 + 严重者封禁**
    如果此玩家不改，管理可加量

## 四、高危设备 / 机械强制报备制度（不报备即违规）

::: danger ⚠️ 强制报备 - 不报备即违规
以下**大型高能、高负载、可毁服机器**，**建造、开机、试运行前必须私信管理员报备**，登记坐标、用途、运行时长，未经报备私自运行一律按卡服违规处罚。
:::

以下**大型高能、高负载、可毁服机器**，**建造、开机、试运行前必须私信管理员报备**，登记坐标、用途、运行时长，未经报备私自运行一律按卡服违规处罚：

1. 飞行器轰炸机、高速弹射飞行器、世界吞噬机（世吞）
    
2. 各类大型轨道炮、TNT 大炮、连发炮组、远程爆破装置
    
3. 大型高频红石阵列、大规模脉冲红石设备
    
4. 大型全自动刷怪机、刷物机、刷沙机、刷图机、刷线机、掉落物堆积机器
    

✅ **报备通过：可合法使用** ❌ **私自建造运行：直接封禁 7 天 + 强制拆除设备** ⚠️ 报备设备使用中一旦出现卡顿、掉 TPS、服务器负载异常，需立刻停机，拒不停机直接顶格处罚。

::: tip 💡 小型刷物机允许使用
**单机、低频、低负载的小型刷物机 / 刷沙机 / 刷线机允许自由建造使用**，无需报备。判断标准：**单台机器、不阵列化、不高频、不堆叠掉落物**。一旦机器规模扩大（阵列、高频、堆积掉落物）即视为大型机器，必须报备。任何刷物机一旦造成卡顿、TPS 暴跌，立即停机拆除，拒不执行按卡服条例处罚。
:::

## 五、服务器游玩注意事项（常规底线）

1. 禁止长时间挂机占用地狱门加载器、恶意常驻区块加载造成服务器持续负载。
    
2. 低 Y 轴底层禁止利用盔甲架挂机、卡死挂机线程；底层挂机必须做好防蝙蝠、防实体堆积措施，违规造成卡顿按卡服条例处罚。
    
3. 禁止滥用高频指令、重复指令刷屏拖垮服务器主线程。
    
4. 禁止散播消极言论、煽动退服、抹黑服务器、挑动玩家对立。
    
5. 尊重管理团队执法，禁止挑衅、对线、辱骂管理员。
    

## 六、分级处罚标准（统一固定、公开透明）

1. **轻度违规（无意小型卡区块、轻微违规摆放）** 处罚：口头警告、当场整改、限时拆除
    
2. **中度违规（实体堆积、违规小型机器、恶意刷屏）** 处罚：禁言 1–3 天、封禁 1–3 天、清理违规数据
    
3. **重度违规（私自部署高危机器、造成服务器卡顿 TPS 暴跌）** 处罚：**固定小黑屋 7 天**、强制拆除全部违规设备
    
4. **严重违规（触发看门狗崩服、恶意大规模熊毁、传播毁服教程、屡教不改）** 处罚：**永久封禁、永久拉黑、清除全部建筑与数据**
