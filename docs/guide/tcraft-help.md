# T Craft 服务器指令帮助

TCraft 服务器自研帮助插件 `tcraft-help` 提供了一系列便捷指令，涵盖玩家常用功能、聊天交互、管理员运维、实体管理等场景。

::: tip 💡 使用提示
- 所有指令均在**游戏内聊天框**输入，输入完成后按回车执行
- `<方括号>` 表示必填参数，`[方括号]` 表示选填参数
- 忘记指令时，可随时在游戏内输入 `/t help` 查看完整帮助（支持点击翻页）
- 部分指令需要对应权限，普通玩家可用的指令均已默认开放
- 主命令 `/t` 可用别名 `/tcraft`，例如 `/tcraft bal` 等同于 `/t bal`
:::

## 玩家命令（所有玩家可用）

| 命令 | 别名 | 功能 |
|------|------|------|
| `/cd` | — | 打开主菜单（签到/商店/市场/回收/传送/帮助等） |
| `/fly` | — | 切换飞行模式（创造/旁观模式不可用） |
| `/player` | `/players`、`/online` | 查看在线玩家列表 |
| `/t bal` | `/t balance` | 查看自己的积分余额 |
| `/t jf <玩家> <积分>` | — | 向其他玩家转账积分 |
| `/t hjf <兑换码>` | — | 领取兑换码奖励 |
| `/t tell <玩家> <内容>` | — | 向在线玩家发送私信 |
| `/t forum [密码]` | — | 绑定/修改论坛账号密码 |
| `/t dl` | `/t datelogs` | 查看更新日志 |
| `/t pingwarn <on\|off>` | — | 开启/关闭网络延迟提示 |
| `/t help [页码]` | — | 查看帮助（点击翻页） |

## 聊天命令（无需 / 前缀）

以下操作直接在聊天框输入即可触发，无需 `/` 前缀。

| 输入 | 功能 |
|------|------|
| `@玩家名` | 提及在线玩家（10 秒内最多 3 次，单条消息最多 5 人） |
| `qx` | 取消当前输入模式（购买/上架/管理员设置） |
| `数字`（购买会话中） | 购买商店物品的指定数量 |
| `数字`（上架会话中） | 设置市场上架物品价格 |

::: warning ⚠️ 聊天命令须知
- `@提及` 有频率限制：**10 秒内最多 3 次**，单条消息最多提及 **5 人**，防止刷屏
- `qx` 仅在处于"输入模式"（购买/上架/管理员设置等等待玩家输入数字的状态）时生效
- 在输入模式下输入数字会被系统拦截作为数量/价格，如需正常聊天请先输入 `qx` 退出输入模式
:::

## 管理员命令（OP 或 tcraft.admin）

::: danger ⚠️ 管理员专用
以下命令仅限 **OP 或拥有 `tcraft.admin` 权限**的管理员使用，普通玩家无法执行。部分命令（如 `/t del`、`/t admin`）仅限 OP。请谨慎操作，避免误删数据或影响服务器运行。
:::

| 命令 | 功能 |
|------|------|
| `/t reload` | 重载所有插件系统（数据保存→配置重载→重启服务） |
| `/t status` | 查看插件运行状态 |
| `/t gjf <玩家> <积分>` | 给玩家发放积分 |
| `/t ghjf <积分> [数量] [可重复]` | 生成兑换码 |
| `/t on` / `/t off` | 开启/关闭维护模式 |
| `/t sick <玩家> [原因]` | 管控玩家 |
| `/t sickd <玩家>` | 解除管控 |
| `/t jy <玩家> <原因>` | 禁言玩家（支持离线） |
| `/t jyd <玩家>` | 解除禁言（支持离线） |
| `/t web <on\|off\|status>` | 开启/关闭/查看 Web API 服务 |
| `/t admin <新密码>` | 设置 Web 后台管理员密码（仅 OP） |
| `/t del <玩家>` | 彻底删除玩家所有数据（仅 OP） |
| `/t dl add <内容>` | 添加更新日志 |
| `/t dl delete <id>` | 删除更新日志 |

::: danger 🚫 高危操作警告
- `/t del <玩家>` 会**彻底删除该玩家的所有数据**且**不可恢复**，执行前务必再三确认玩家名
- `/t reload` 会重载所有插件系统，期间部分功能可能短暂不可用，建议在低峰期执行
- `/t on` / `/t off` 切换维护模式会影响玩家进出，请提前公告
:::

## 实体管理命令（OP）

用于排查服务器卡顿、实体过多等问题，默认仅 OP 可用。

| 命令 | 别名 | 功能 |
|------|------|------|
| `/shows sound` | — | 打开声音列表 |
| `/shows entities` | — | 打开实体统计 GUI |
| `/shows blockentities` | — | 打开方块实体统计 GUI |
| `/killentities <类型> [confirm\|cancel]` | `/kille` | 击杀指定类型实体（需确认） |
| `/entitygui` | — | 重新打开实体统计 GUI |

::: warning ⚠️ 实体管理须知
- `/shows` 系列命令别名：`/show`、`/s`，例如 `/s entities` 等同于 `/shows entities`
- `/killentities` 为**不可撤销**操作，请务必先用 `/shows entities` 确认实体类型后再执行 `confirm`
- 误杀村民、命名实体等有用实体将无法恢复，操作前请仔细核对类型
:::

## /cd 菜单功能模块

`/cd` 主菜单集成了服务器绝大部分功能入口，无需记忆命令，点击即可使用。

### 玩家功能

每日签到、积分排行榜、通知系统、随机传送、公共传送点、帮助中心、返回主城、积分商店、全球市场、技能系统、一键回收、垃圾箱、领地管理、在线玩家、投诉玩家

### 管理员功能（菜单槽位 40）

游戏模式切换、时间设置、商店管理、回收管理、举报管理、维护模式、完全隐身、卡服管理、签到/市场/每小时奖励设置

::: tip 💡 菜单使用建议
- 日常操作推荐优先使用 `/cd` 菜单，比记忆命令更直观
- 管理员功能入口集中在菜单槽位 40，仅管理员可见
- 各功能模块的详细说明请参考帮助中心对应文档
:::

## 权限节点

| 权限 | 默认 | 说明 |
|------|------|------|
| `tcraft.fly` | 所有玩家 | 使用 `/fly` |
| `tcraft.admin` | OP | 管理员权限 |
| `tcraft.mute` | OP | 禁言管理 |
| `youer.shows` | OP | 使用 `/shows` |
| `youer.shows.kill` | OP | 击杀实体 |

::: tip 💡 权限说明
- `tcraft.fly` 默认对所有玩家开放，其余管理类权限默认仅 OP 拥有
- 完整权限列表（含 `/shows` 子权限 `youer.shows.sound`、`youer.shows.entities`、`youer.shows.blockentities`、`youer.shows.reopen`）均默认仅 OP 可用
- 如需授予某玩家管理权限，服主可通过权限插件单独配置
:::
