# 指令总表

所有指令在游戏内聊天框输入。忘了就输 `/t help`。

`<尖括号>` 是必填，`[方括号]` 是选填。`/t` 可以写成 `/tcraft`。

## 玩家指令

| 指令 | 别名 | 作用 |
|---|---|---|
| `/cd` | — | 打开主菜单 |
| `/fly` | — | 开关飞行（创造/旁观模式无效） |
| `/player` | `/players`、`/online` | 看谁在线 |
| `/t bal` | `/t balance` | 查自己积分 |
| `/t jf <玩家> <数量>` | — | 转积分给别人 |
| `/t hjf <兑换码>` | — | 用兑换码 |
| `/t tell <玩家> <内容>` | — | 私信 |
| `/t forum [密码]` | — | 绑定/改论坛密码 |
| `/t dl` | `/t datelogs` | 看更新日志 |
| `/t pingwarn <on\|off>` | — | 开关延迟提示 |
| `/t help [页码]` | — | 看帮助 |
| `/t chainmine` | `/t cm` | 开关连锁挖矿 |

## 聊天框直接输入（不用 `/`）

| 输入 | 作用 |
|---|---|
| `@玩家名` | 提醒某个人（10 秒内最多 3 次，一条消息最多 @ 5 人） |
| `qx` | 退出"输入模式" |
| 数字 | 在购买/上架界面里表示数量或价格 |

::: warning 卡在输入模式了？
买东西、上架时系统会等你输数字，这时正常聊天也会被当成数字。
输 `qx` 退出就行。
:::

## 管理员指令

::: danger 需要 OP 或 `tcraft.admin`
下面的指令普通玩家用不了。带"仅 OP"的连管理员权限都不够。
:::

| 指令 | 作用 |
|---|---|
| `/t reload` | 重载所有系统 |
| `/t status` | 看插件运行状态 |
| `/t gjf <玩家> <积分>` | 给玩家发积分 |
| `/t ghjf <积分> [数量] [可重复]` | 生成兑换码 |
| `/t on` / `/t off` | 开关维护模式 |
| `/t sick <玩家> [原因]` | 管控玩家 |
| `/t sickd <玩家>` | 解除管控 |
| `/t jy <玩家> <原因>` | 禁言（可对离线玩家） |
| `/t jyd <玩家>` | 解除禁言 |
| `/t web <on\|off\|status>` | Web 服务开关 |
| `/t admin <新密码>` | 设后台密码（仅 OP） |
| `/t del <玩家>` | 删除玩家全部数据（仅 OP） |
| `/t dl add <内容>` | 加更新日志 |
| `/t dl delete <id>` | 删更新日志 |

::: danger 三个不能后悔的
- `/t del <玩家>` —— 数据**彻底删除**，不可恢复。执行前反复确认名字
- `/killentities` —— 杀的实体回不来，先用 `/shows entities` 看清楚类型
- `/t off` —— 切维护模式会让玩家进不来，提前公告
:::

## 实体管理（OP）

服务器卡的时候用来查是哪种实体太多。

| 指令 | 别名 | 作用 |
|---|---|---|
| `/shows entities` | `/s entities` | 实体统计界面 |
| `/shows blockentities` | — | 方块实体统计 |
| `/shows sound` | — | 声音列表 |
| `/killentities <类型> [confirm\|cancel]` | `/kille` | 杀掉指定类型实体 |
| `/entitygui` | — | 重新打开统计界面 |
