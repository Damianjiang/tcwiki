# 坐下、躺下、爬行

## 指令

| 指令 | 作用 |
|---|---|
| `/sit` | 原地坐下 |
| `/lay` | 躺下 |
| `/crawl` | 切换爬行（能钻过 1 格高的缝隙） |
| `/gsit toggle` | 开关"右键方块自动坐下" |

## 怎么起来

再输一次对应指令，或者移动、跳跃。

## 自动坐下

站在台阶、楼梯、椅子上右键，会自动坐下。不想要这个行为就 `/gsit toggle` 关掉。

::: tip 爬行能钻缝
`/crawl` 打开后角色变成爬行姿态，能通过只有 1 格高的空间。探索地下洞穴或建筑夹层时有用。
:::

坐下、躺下只是动作，不改变任何属性。
