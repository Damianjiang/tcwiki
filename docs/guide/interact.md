# 休息与互动

::: tip 💡 功能简介
服务器提供**坐下、躺下、爬行**等休闲互动动作，让你可以在台阶、椅子等方块上惬意休息，也支持爬行穿过 1 格高的缝隙，探索地图更方便。
:::

## 常用指令

| 指令 | 说明 |
|------|------|
| `/sit` | 立即原地坐下 |
| `/lay` | 躺下休息 |
| `/crawl` | 切换爬行姿态（可穿过 1 格高的缝隙） |
| `/gsit toggle` | 开关"右键方块自动坐下"功能 |

## 使用方式

- **自动坐下**：站在台阶、楼梯、椅子等可坐方块上，右键即可自动坐下（可在设置中关闭）。
- **手动动作**：直接输入 `/sit`、`/lay`、`/crawl` 即可做出对应动作。
- **取消动作**：再次输入对应指令，或移动、跳跃即可起身。

::: tip 💡 小提示
- 爬行姿态可以让你钻过只有 1 格高的缝隙，是探索地下与建筑缝隙的好帮手。
- 坐下、躺下只是休闲动作，不会影响你的任何属性或状态。
:::
