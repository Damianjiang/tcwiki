# 关于服务器

T Craft 是一个 Minecraft Java 版公益服，2021 年开服，主打原版生存。

## 基本信息

| 项目 | 详情 |
|---|---|
| 服务器名 | T Craft |
| 版本 | Java 1.21.11 |
| 地址 | `tcraft.wdsjfwq.com` |
| 官网 | https://tcraft.pages.dev |
| 开服时间 | 2021 年至今 |
| 网站制作 | Damian2012 |

## 玩法

以原版生存为主，保留 MC 核心机制，只加了轻量辅助插件：

- **主菜单 `/cd`** —— 签到、商店、市场、传送、领地
- **连锁挖矿** —— 挖矿脉、砍树不用一块块点
- **领地系统** —— 保护你的建筑
- **RPG 技能** —— 挖矿钓鱼打怪都能升级

详细玩法看左边「帮助中心」的对应文档。
