# 关于服务器

## 服务器简介

**T Craft 是面向 Minecraft Java 版玩家打造的高品质公益服生存服务器**

以稳定流畅、公平纯净、高安全、长期运营为核心理念，致力于为每一位方块爱好者打造安心、友好、长久的线上家园。服务器采用企业级硬件与优化架构，搭配全时段高防防护，有效抵御各类攻击与异常流量，实现24小时不间断稳定运行。

服务器主打原版纯净生存，保留MC核心玩法与全部特性，同时搭载便捷工具等轻量化插件，平衡原汁原味与游戏体验。无论是单人开荒、团队建造、红石生电，还是冒险探索、社区互动，都能找到属于自己的乐趣。

T Craft 定期举办主题活动、建筑赛事、生存挑战等社区内容，持续更新优化玩法与地图，让长期游玩不枯燥。

从孤身一人到伙伴同行，从一方小屋到宏伟城邦，T Craft 不止是服务器，更是属于所有 MC 玩家的共同家园。欢迎加入 T Craft，与万千伙伴一起，在方块世界里创造无限可能！
