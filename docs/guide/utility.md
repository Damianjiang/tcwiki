# 实用小功能

这些功能默认开启，不需要设置。

## 掉落物自动堆叠

地上的同类掉落物会自动合并成一堆，捡起来更方便，也不会堆满地面。

**你不用做任何操作。**

## 伤害数字显示

攻击生物或玩家时，头顶会飘出伤害数值和对方剩余血量。

想关掉：输入 `/di`，再输一次重新打开。默认是开着的。

## 查合成表

服务器加了自定义配方，普通客户端看不到。

**装 JEI 或 REI 模组**（Fabric / NeoForge 客户端）后，打开合成表界面（默认 `E` 键，查用途按 `R`），就能看到服务器所有物品怎么合成，包括自定义装备。

## 多版本进服

不同 Minecraft 版本的客户端可以进同一台服务器，不用统一版本。

如果提示版本不兼容，把客户端更新到较新版本再试。

## 聊天不会被举报

服务器关闭了聊天举报签名，你的聊天内容**不会被别的玩家拿去跨服举报**。

正常聊天不受影响。
