# 实用小功能

服务器还内置了一系列贴心小功能，让游玩更顺手。以下多为自动化或轻量功能，无需复杂设置。

## 物品自动堆叠

地面上的同类掉落物、物品栏中的堆叠会被自动合并，减少地面杂物、降低卡顿，世界更干净，捡东西也更省心。

## 伤害数字显示

攻击生物或玩家时，会显示造成的伤害数值与剩余血量，战斗反馈更直观。

- 开关指令：`/di`（开启 / 关闭伤害显示）
- 默认对所有玩家开启，不喜欢可在设置中关闭。

## 合成表查询（客户端）

服务器同步了全部自定义合成配方。如果你安装了 **JEI / REI 等模组**（Fabric / NeoForge 客户端），打开合成表（默认 `E` 或 `R` 键）即可查看服务器所有物品的合成方式，包括自定义装备与道具。

## 多版本进入

服务器支持**多个 Minecraft 客户端版本**直接进入同一台服务器，无需更换游戏版本即可和朋友一起玩。若提示版本不兼容，请尝试将客户端更新到较新版本。

## 聊天隐私保护

服务器已关闭聊天消息的"举报签名"机制，你的聊天内容不会被用于跨客户端举报，聊天更安心。（该机制仅影响 1.19.1+ 客户端的举报功能，不影响正常聊天。）

## 进服欢迎信息

每次进服会显示服务器的欢迎信息（图标、描述、版本等）以及由服务器配置的欢迎语与快捷菜单入口。
