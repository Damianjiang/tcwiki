# 连锁挖矿

手持镐、斧、锹、锄挖方块时，可以一次性挖掉相连的同类方块——挖矿脉、砍树不用再一块块点。

## 怎么开关

**手持工具，对着空气右键**即可切换。

- 开启时聊天栏提示：`[TCraft] 连锁挖矿已开启`
- 关闭时提示：`[TCraft] 连锁挖矿已关闭`

::: tip 提示
- 只有手持 **镐 / 斧 / 锹 / 锄** 时右键才会响应，空手或拿方块右键不会切换
- 开关状态**只保存在本次在线期间**，退出游戏或服务器重启后会自动回到"关闭"，下次进服需要重新开启
- 也可以输入 `/t chainmine`（或 `/t cm`）切换，`/t chainmine status` 只看当前状态
:::

## 怎么用

**开启后，按住 Shift 再挖方块**，就会连锁破坏周围的同类方块。

- **按住 Shift 挖** → 连锁
- **不按 Shift 挖** → 和原版完全一样，只挖一块

::: warning 注意
连锁时**按住 Shift 是必须的**。如果你松开 Shift 挖方块，就只有一块被挖掉，这是正常的，不是没生效。
:::

## 支持哪些工具和方块

工具和方块必须**对应**，不会出现"拿镐连锁泥土"这种情况：

| 手持 | 可以连锁 | 不会连锁 |
|------|----------|----------|
| 镐 | 石头、各类矿石、深板岩等石类方块 | 泥土、沙子、木头 |
| 斧 | 原木、木头类方块 | 石头、泥土、树叶 |
| 锹 | 泥土、沙子、沙砾等土类方块 | 石头、木头 |
| 锄 | 干草块等 | 石头、木头 |

**工具等级也要够**：木镐连锁不了黑曜石（挖了也不掉），需要用钻石镐或下界合金镐。

默认只连锁**和第一块完全相同的方块**——挖煤矿石不会连带旁边的铁矿石。

## 耐久会正常消耗

连锁**不是免费挖掘**，每多挖一块都会消耗工具耐久：

- 起始那块由游戏原版扣耐久
- 后续每一块都会按原版规则扣耐久
- 附魔「耐久」同样生效（等级越高，消耗越慢）
- 附魔「无法破坏」的工具不消耗耐久
- **耐久用尽时连锁会自动停止**，工具正常损坏，并提示"工具已损坏，连锁停止"

## 一次最多挖多少

为了防止卡顿和误操作，连锁有上限：

- 一次最多 **64 块**（不含你亲手挖的那一块）
- 以第一块为中心的 **8 格范围**内，超出范围的方块不会连锁

所以挖大片石头时，不会一口气把半座山挖空。

## RPG 自定义物品不能连锁

服务器里的 **RPG 武器 / 自定义工具无法连锁**。

这类物品的耐久、属性、掉落都由 RPG 系统单独管理，允许连锁会绕过这些规则。判断是自动的，你不需要做任何设置——拿着 RPG 镐挖方块时不会触发连锁，也不会报错。

::: tip 普通工具不受影响
自己附魔的镐（时运、效率、耐久）、用铁砧改过名的镐，都**照常可以连锁**。
:::

## 常见问题

### 右键没反应，开关切不了？

1. 确认手里拿的是**镐/斧/锹/锄**，不是别的物品
2. 确认是对着**空气**右键（准星对着天空或远处），不是对着方块
3. 如果还是不行，直接用命令：`/t chainmine`

### 开了但挖了不连锁？

1. 确认**按住 Shift** 了
2. 确认工具和方块类型匹配（镐挖石头、斧砍树）
3. 确认工具等级够（木镐挖不了黑曜石）
4. 如果拿着 RPG 自定义工具，连锁是被**主动禁用**的

### 为什么只连锁了几块就停了？

可能的原因：

- 达到了 64 块上限
- 超出了 8 格范围
- 工具耐久耗尽
- 周围没有同类型的方块了

### 会不会影响别人？

连锁破坏的每一块都会经过服务器的保护检查，**领地内、保护区内的方块不会被连锁破坏**。
