# 传送

## 传送到玩家身边

| 指令 | 作用 |
|---|---|
| `/tpa <玩家>` | 请求传送到对方那里 |
| `/tphere <玩家>` | 请求对方传送到你这里 |
| `/tpaccept` | 同意（也可以点聊天框里的 [接受]） |
| `/tpdeny` | 拒绝（点 [拒绝并拉黑] 会顺手拉黑对方） |

::: warning 别乱发传送请求
超时没人理会自动取消。给陌生人发会暴露你的坐标，想屏蔽某人用下面的 `/denys`。
:::

## 家

| 指令 | 作用 |
|---|---|
| `/sethome <名字>` | 设一个家 |
| `/home <名字>` | 回家 |
| `/homes` | 列出你所有的家 |
| `/setdefaulthome <名字>` | 设默认家（`/home` 不写名字时去这个） |
| `/delhome <名字>` | 删掉一个家 |

能设几个家看你的权限等级。

## 主城和野外

| 指令 | 作用 |
|---|---|
| `/spawn` | 回主城 |
| `/rtp` | 随机传送到野外（找新地方建家时用） |

## 传送点

| 指令 | 作用 |
|---|---|
| `/warp <名字>` | 去指定传送点 |

不知道有哪些传送点，就在主城看告示牌或问管理员。

## 回退

`/back` 回到上一次的位置，详见 [回退传送](/guide/death-back)。

## 屏蔽别人的传送请求

| 指令 | 作用 |
|---|---|
| `/denys add <玩家>` | 拉黑，不再收到他的请求 |
| `/denys remove <玩家>` | 取消拉黑 |
| `/denys` | 看当前黑名单 |

## 管理员

| 指令 | 作用 |
|---|---|
| `/tpall` | 把所有人传送到你身边 |
| `/tplogout <玩家>` | 传送到某人最后下线的地方 |
| `/setwarp` / `/delwarp` | 管理传送点 |
| `/setspawn` / `/delspawn` | 管理主城 |
