# 传送功能指令

::: tip 💡 传送简介
服务器提供多种传送指令，方便玩家快速移动与互助。传送请求类指令需对方同意后才生效。
:::

## 请求类传送

需要对方玩家同意才能完成传送：

| 指令 | 说明 |
|------|------|
| `/tpa <玩家名>` | 向指定玩家发送传送请求（传送到对方身边） |
| `/tphere <玩家名>` | 请求将指定玩家传送到自己身边 |
| `/tpaccept` | 接受其他玩家发来的传送请求 |
| `/tpdeny` | 拒绝其他玩家发来的传送请求 |

::: warning ⚠️ 传送请求须知
- 传送请求有**时效限制**，超时未回应将自动取消
- 请仅向信任的玩家发送传送请求，避免暴露领地坐标
- 收到陌生人的传送请求时可选择 `/tpdeny` 拒绝
:::

## 直接传送

| 指令 | 说明 |
|------|------|
| `/tp <玩家名>` | 直接传送到指定玩家身边 |
| `/tp <x> <y> <z>` | 传送到指定坐标位置 |
| `/spawn` | 立即返回服务器出生点 |

::: tip 💡 领地传送
如需传送到自己的领地，可使用领地系统的传送指令 `/dom tp <领地名>`，详见 [领地系统帮助](/guide/residence)。
:::
