# 经济系统完整教程

TCraft 经济系统以**积分**为核心货币，玩家可以通过多种方式获取积分，并在商店、市场等场所消费。

## 获取积分方式

### 每日签到

- 入口：主菜单 → 每日签到
- 奖励：由管理员设置（默认 10 积分/天）
- 规则：每天只能签到一次，次日重置

### 在线奖励

- 奖励：由管理员设置（默认 5 积分/小时）
- 规则：每在线满1小时自动发放，系统自动记录在线时间

### 物品回收

- 入口：主菜单 → 物品回收
- 方式：将可回收物品放入回收箱换取积分
- 一键回收：扫描背包中所有可回收物品，快速回收

## 积分消费方式

### 积分商店

- 入口：主菜单 → 积分商店
- 功能：使用积分购买管理员设置的商品
- 操作：点击商品即可购买

### 全球市场

- 入口：主菜单 → 全球市场

**浏览店铺：** 市场首页显示所有卖家店铺列表，点击店铺进入查看商品

**购买商品：** 进入卖家店铺后，点击商品即可购买，物品自动进入背包

**上架商品：** 我的商店 → 上架物品 → 放入物品 → 设置价格 → 确认上架

**下架商品：** 我的商店 → 点击商品 → 确认下架

**上架限制：** 每位玩家最多上架 10 个商品

## 积分转账功能

### 服务器内转账

**指令格式：** `/tcraft jf <玩家名> <积分数量>`

**功能说明：** 将指定数量的积分转账给服务器内的其他玩家

**使用示例：** `/tcraft jf Steve 100`

说明：将 100 积分转账给名为 Steve 的玩家

### 转账注意事项

① 转账前请确认玩家名称正确，避免转错玩家

② 确保账户内有足够的积分余额

③ 转账操作无法撤销，请谨慎操作

④ 只能转账给在线玩家

## 管理员功能

- **商店管理：** 主菜单 → 管理员菜单 → 商店管理 → 添加/删除商品
- **回收管理：** 主菜单 → 管理员菜单 → 回收管理 → 设置可回收物品及价格
- **系统设置：** 可调整签到奖励、每小时奖励、市场上限等

## 菜单操作流程

```
主菜单
├── 返回出生点
├── 每日签到
├── 积分商店 → 购买商品
├── 全球市场 → 店铺列表 → 购买商品
│           └── 我的商店 → 上架/下架商品
├── 物品回收 → 回收列表 → 回收箱
│           └── 一键回收
└── 管理员菜单（仅管理员）
    ├── 商店管理
    ├── 回收管理
    └── 系统设置
```

## 注意事项

① 积分数据自动保存，但建议重要交易后确认余额

② 市场交易购买后无法退款，请确认后再购买

③ 达到上架上限后，新物品会返回背包
