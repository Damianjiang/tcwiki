# 积分与交易

服务器用**积分**当钱。赚积分、花积分、玩家之间转账，都在这里。

所有操作都能在 `/cd` 菜单里点，不用记指令。

## 怎么赚积分

| 方式 | 怎么做 | 能拿多少 |
|---|---|---|
| 每日签到 | `/cd` → 每日签到 | 每天一次，数额看服务器设置 |
| 在线奖励 | 挂着就行 | 每满 1 小时自动发 |
| 物品回收 | `/cd` → 物品回收，把东西放进回收箱 | 按回收价 |

回收箱支持"一键回收"，会把背包里所有能回收的东西一次收掉。

## 怎么花积分

### 积分商店

`/cd` → 积分商店，点商品买。商品和价格由管理员配置。

### 全球市场（玩家之间买卖）

`/cd` → 全球市场

| 想做什么 | 步骤 |
|---|---|
| 逛别人的店 | 首页是店铺列表，点进去看商品 |
| 买东西 | 进店铺，点商品，自动进背包 |
| 卖东西 | 我的商店 → 上架物品 → 放物品 → 定价 → 确认 |
| 下架 | 我的商店 → 点商品 → 确认下架 |

**每人最多挂 10 件**。满了新物品会退回背包。

::: warning 买之前看清楚
市场是玩家自由定价，**买完不能退**。价格和物品真假自己判断。
:::

## 转账给别人

```
/t jf <玩家名> <数量>
```

例：`/t jf Steve 100` —— 给 Steve 转 100 积分。

::: warning 转账前确认三件事
- **玩家名对不对**（转错了退不回来，服主不受理）
- **余额够不够**（不够会失败）
- **对方必须在线**（离线的收不到）
:::

## 管理员部分

`/cd` → 管理员菜单

- **商店管理** —— 加/删商品、改价格
- **回收管理** —— 设置哪些物品能回收、回收价多少
- **系统设置** —— 签到奖励、每小时奖励、市场上架上限
