# 服务器重启更新指令

## 指令说明

**指令：** `/tcraft gx`

**功能：** 服务器重启更新，5 秒倒计时后执行 Paper 服务端重启指令

::: danger ⚠️ 管理员专用
本指令仅限 **OP 或拥有 `tcraft.admin` 权限**的管理员使用，普通玩家无法执行。重启会导致所有在线玩家断开连接，请谨慎操作。
:::

## 权限要求

只有 OP 或拥有 `tcraft.admin` 权限的玩家可以使用

## 执行流程

1. 检查权限和是否已在重启中
2. 开始 5 秒倒计时
3. 每秒向所有在线玩家发送倒计时消息
4. 倒计时结束后执行 `restart` 命令

::: tip 💡 重启说明
- 重启通常在数秒内完成，玩家可重新连接服务器
- 重启用于应用更新、清理内存、修复异常等
- 重启不会清除玩家数据与建筑，请放心
:::
