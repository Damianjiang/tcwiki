# 死亡返回

::: tip 💡 功能简介
不小心死掉、东西掉在很远的地方？服务器提供**死亡返回**功能，让你随时回到上一次死亡的位置，方便找回掉落的物品。
:::

## 常用指令

| 指令 | 说明 |
|------|------|
| `/back` | 传送回上一次死亡的位置 |

## 使用说明

- 每次死亡后，系统都会记录你的死亡坐标。
- 输入 `/back` 即可一键传送回该位置（请确保目的地安全，避免卡在方块内）。
- 如果你之后再次发生传送或死亡，记录的位置会更新为最新一次。

::: warning ⚠️ 注意事项
- 死亡掉落的物品仍有**存在时间限制**（通常为 5 分钟），请尽快使用 `/back` 找回。
- 部分特殊场景（如副本、小游戏）可能不支持死亡返回，请以游戏内实际提示为准。
:::
