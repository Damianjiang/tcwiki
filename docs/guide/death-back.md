# 回退传送 `/back`

传送后后悔了、死后想捡回掉落物，用这个回到上一次的位置。

## 用法

```
/back
```

系统会自动记录你**每次传送前**的坐标（`/tpa`、`/warp`、`/home`、`/spawn`、死亡重生都算）。输入 `/back` 就回到那里。

## 三个常见场景

| 情况 | 做法 |
|---|---|
| 传过去发现不是想去的地方 | `/back` 回原处 |
| 死了想捡掉落物 | 重生后 `/back` 回死亡点，趁物品没消失赶紧捡 |
| 跑太远想回去 | `/back` |

::: warning 注意
- **掉落物会消失**，死后尽快 `/back`
- 副本、小游戏里可能不支持，以游戏内提示为准
- 每次传送都会覆盖上一次的记录，只能回退一步
:::
