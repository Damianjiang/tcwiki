# 回退传送

::: tip 💡 功能简介
服务器提供**回退传送**功能（`/back`），让你随时传送到上一次的位置。无论是传送后想回去、死后回到死亡地点、还是探索后返回，都可以一键回到你离开前的坐标。
:::

## 常用指令

| 指令 | 说明 |
|------|------|
| `/back` | 传送到上一次的位置（如传送前、死亡重生前等） |

## 使用说明

- 每次发生传送（包括 TPA、Warp、Home、Spawn、死亡重生等），系统都会自动记录你**离开前的坐标**。
- 输入 `/back` 即可一键传送回该位置（请确保目的地安全，避免卡在方块内）。
- 如果你之后再次发生传送，记录的位置会更新为最新一次。

::: tip 💡 常见场景
- **传送后悔了**：`/tpa`、`/warp`、`/home`、`/spawn` 等操作后想回原位，直接 `/back`
- **死后找回掉落物**：死亡重生后 `/back` 可回到死亡地点，趁物品未消失赶紧捡回来
- **探索后返回**：去远处看了看想回来，`/back` 一键回退
:::

::: warning ⚠️ 注意事项
- 死亡掉落的物品仍有**存在时间限制**（通常为 5 分钟），请尽快使用 `/back` 找回
- 部分特殊场景（如副本、小游戏）可能不支持回退，请以游戏内实际提示为准
- 权限 `tpa.back`（默认对所有玩家开放）
:::
