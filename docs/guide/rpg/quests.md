# 任务系统

RPG 系统中的 **任务模块** 用于承载主线与日常任务，完成任务可以获取经验、货币、材料与专属奖励，是引导玩家成长的主要途径之一。

::: tip 💡 怎么接任务
输入 `/cd` 打开主菜单，找到 **RPG 面板**；或直接输入 `/rpgcd` 一键打开，在面板中查看当前可接取的任务。
:::

## 当前状态

服务器已接入任务系统框架，但 **自定义任务内容目前仍在筹备中**，暂未开放可供接取的正式任务。

待任务内容配置完成后，本页会补充：

- **主线任务**：贯穿服务器剧情的长期目标；
- **日常任务**：每日可重复完成的短任务，稳定产出奖励；
- **任务奖励说明**：各类任务对应的奖励类型。

::: tip 💡 过渡期建议
任务系统开放前，你仍可通过以下方式稳定成长：
- 用 `/cd` 主菜单的 **技能** 提升技能等级，解锁属性与能力；
- 挑战世界 Boss 与特色怪物获取 RPG 材料；
- 进入副本（如试炼地牢 1）刷取高级奖励；
- 在 RPG 面板中打造与升级装备。

任务系统开放后，我们会第一时间在 RPG 面板与本站更新。
:::
