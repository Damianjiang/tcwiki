# 副本系统

副本是 RPG 系统中 **组队挑战** 的玩法：进入独立的副本地图，清剿刷怪点与 Boss，获取高级奖励。副本独立于主世界，不会破坏你的家园。

::: tip 💡 怎么进入
输入 `/cd` 打开主菜单，找到 **RPG 面板**；或直接输入 `/rpgcd` 一键打开，在面板中选择副本进入。部分副本需要组队，并设有 **队伍准备确认** 机制（队长发起后，队员确认就绪即可进入）。
:::

## 已开放副本

### 试炼地牢 1

- **类型**：单人战斗试炼副本。
- **内容**：内含普通 / 强化地牢守卫与铁卫等敌人，考验你的战斗能力。
- **难度选择**：支持多档难度（含「简单」档，怪物血量与伤害降至 70%），新手也能体验。
- **冷却**：设有每日进入冷却，避免刷取。
- **奖励**：通关后由副本奖励发放战利品。
