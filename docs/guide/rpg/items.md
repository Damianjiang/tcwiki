# 物品与合成

RPG 系统提供了大量 **自定义装备、武器、护甲、宝石与材料**，远多于原版内容。这些物品无法用原版工作台合成，需要在 **RPG 面板** 中查看与打造。

::: tip 💡 打开方式
输入 `/cd` 打开主菜单，找到 **RPG 面板** 进入；或直接输入 `/rpgcd` 一键打开。物品、配方与打造都在面板内完成。
:::

## 物品大类

RPG 物品按用途分为几十个类别，常见的包括：

| 类别 | 说明 |
|------|------|
| 护甲 | 头盔、胸甲、护腿、靴子，部分带有套装效果 |
| 武器 | 剑、巨剑、双手剑、匕首、长枪、长柄刀、弓、弩等 |
| 消耗品 | 食物、药水、临时增益道具 |
| 材料 | 打造装备所需的基础锭、精华、素材 |
| 宝石 | 可镶嵌提升属性的宝石 |
| 工具 | 专属镐、锹等采集工具 |
| 法杖 / 魔杖 | 释放法术的远程武器 |
| 饰品 / 护符 | 提供被动加成的装备栏物品 |

## 基础材料

高级装备都由基础材料层层打造而来，例如：

- **钢锭**：由铁锭在锻造站提炼而成，是大量钢制装备的基底。
- **凋零精华**：击败凋零骷髅相关怪物后获取，用于打造亡灵系装备与法器。
- **火焰精华 / 烈焰之魂**：与火焰、烈焰相关的装备与图腾的核心材料。
- **纯净能量**：一种用于「注能」升级的高阶能量材料。

> 具体每种材料从哪里来、怎么用，请在 RPG 面板的物品详情中查看，避免记错。

## 代表性成品（节选）

下面列出一些有代表性的成品，帮助你对装备体系有个直观印象（完整列表请在 RPG 面板图鉴中查看）：

- **精铁套装**：头盔 / 护甲 / 护腿 / 靴子一套，由钢锭进一步注能打造，是中期主力防具。
- **诅咒凋零颅 / 死亡法老头盔 / 苔藓骷髅颅**：特色头部装备，带有独特外观与属性。
- **地狱弓 / 标记弓**：附带火焰与标记效果的远程武器。
- **火焰图腾**：汇聚火焰精华打造的增益图腾类道具。
- **硬化钢巨剑 / 熔刃 / 双手钢剑**：高伤近战武器，适合不同手感偏好。
- **火焰长枪**：长柄穿刺武器，对特定敌人有优势。
- **钢镐 / 钢锹**：效率更高的专属采集工具。

## 打造方式

装备与道具的打造在 RPG 面板的 **锻造站** 中进行：

1. 在 RPG 面板打开对应的锻造站；
2. 放入所需的材料（基础锭、精华、素材等）；
3. 等待锻造完成，取出成品。

不同档次的装备对应不同的锻造站，越高级的装备所需的材料与打造时间越长。部分顶级装备还需要先用「注能」等方式对基础装备进行升级。

## 专属背包

RPG 系统自带独立的 **装备栏与饰品栏** 面板，和原版背包分开：

- **装备栏**：专门存放盔甲、武器等 RPG 装备；
- **饰品栏**：专门存放戒指、护符、饰品等提供被动加成的物品；
- 这些栏位中的物品在死亡时不会掉落，更安全。

::: tip 💡 小贴士
打造前先确认自己已收集齐材料；不确定的配方、材料来源，直接在 RPG 面板里点开物品看说明最靠谱。
:::
