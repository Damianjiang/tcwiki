# RPG 内容总览

服务器内置了完整的 **RPG 系统**，下面分模块介绍。先说清楚两种打开方式，避免混淆：

::: tip 💡 怎么打开
- **技能系统**：输入主菜单指令 **`/cd`** 打开主菜单，在主菜单中找到 **技能** 并点击进入（不经过 RPG 面板）。
- **装备 / 物品 / 怪物 / 副本 / 任务**：输入 **`/cd`** 打开主菜单，找到 **RPG 面板** 进入；或直接输入 **`/rpgcd`** 一键打开 RPG 面板。
:::

## RPG 系统包含什么

| 模块 | 说明 | 文档 |
|------|------|------|
| 技能成长 | 通过日常行为（挖矿、钓鱼、农耕、战斗等）提升技能等级，解锁属性与能力 | [技能系统](/guide/skills) |
| 装备与道具 | 丰富的自定义武器、护甲、宝石与材料，可在面板中查看与打造 | [物品与合成](/guide/rpg/items) |
| 怪物与 Boss | 大量特色生物与世界 Boss，挑战可获得 RPG 货币与专属材料 | [怪物与 Boss](/guide/rpg/mobs) |
| 副本挑战 | 和好友组队进入副本，挑战刷怪点与 Boss，获取高级奖励 | [副本系统](/guide/rpg/dungeons) |
| 任务系统 | 主线与日常任务，完成任务获取奖励 | [任务系统](/guide/rpg/quests) |

## 新手 RPG 路线建议

1. 进服后先输入 `/cd` 打开主菜单，熟悉其中的 **技能** 与 **RPG 面板** 两个入口。
2. 通过挖矿、钓鱼、农耕、战斗等原版行为积累技能等级，解锁属性与被动能力。
3. 关注技能触发的高级掉落，收集 RPG 专属货币与材料。
4. 在 RPG 面板中查看装备与打造方式，逐步提升战力。
5. 挑战特色怪物与组队副本，获取更丰厚的高级奖励。

::: tip 💡 货币与材料
RPG 体系中有专属货币与各类材料，是打造高级装备的关键，具体用途请在 RPG 面板中查看。
:::
