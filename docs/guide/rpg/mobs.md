# 怪物与 Boss

RPG 系统中包含大量 **特色生物与世界 Boss**，击败它们可以获得 RPG 专属货币、材料与装备部件，是提升战力的重要来源。

::: tip 💡 怎么看 / 怎么打
- 输入 `/cd` 打开主菜单，找到 **RPG 面板**；或直接输入 `/rpgcd` 一键打开，在里面查看怪物图鉴与相关信息。
- 大部分自定义怪物会在世界中自然生成或随活动/事件出现；部分守卫类怪物只在副本内出现。
:::

## 世界 Boss

| 名称 | 简介 | 主要奖励 |
|------|------|----------|
| 神龙 | 巨龙形态的世界级首领，拥有专属 Boss 血条，血量极高，击败后可获得顶级稀有奖励 | 顶级稀有物资 |
| 失落的守护者 | 凋灵骷髅形态的世界 Boss，同样拥有专属血条 | 「强化系列」盔甲与武器部件 |

> 世界 Boss 通常需要在特定时间或活动中挑战，留意服务器公告与 RPG 面板提示。

## 彩蛋 / 特殊 Boss

- **猫娘彩蛋系列 Boss**：数只猫型首领，血量极高、带有发光特效与专属血条，不会自行消失，会主动近战攻击玩家。属于服务器彩蛋级首领。
- **8 倍大史莱姆**：以「实验失败品」为主题的巨型史莱姆 Boss，拥有专属血条、不会消失，击败后稳定产出通用材料「星石」。

## 亡灵系

| 名称 | 简介 | 主要奖励 |
|------|------|----------|
| 矿工僵尸 | 手持钻石镐的僵尸，掉落工具类物品 | 「星石」材料 |
| 掠夺者 / 强化掠夺者 | 人形敌对生物（强化版装备更好），掉落材料 | 「星石」材料 |
| 历经百战的灵魂骑士 | 高血量骷髅首领，免疫弹射物伤害，拥有专属血条与伤害排行 | 「灵魂系列」专属材料 |

## 地牢守卫

出现在试炼地牢等副本中的守卫型怪物：

- **普通地牢守卫 / 强化地牢守卫**：僵尸系守卫，按难度缩放，强化版装备更精良。
- **铁卫**：铁傀儡形态的守卫，负责镇守地牢入口。

## 元素系

- **纯净光灵**：狼形态的光明生物，击败后掉落「光明系列」材料。

## 非战斗实体

- **伤害测试器**：无攻击性的苦力怕假人，用于测试你的武器伤害，不会反击。

## 通用材料说明

击败怪物后常见的 RPG 材料包括：

- **星石**：通用基础材料，多种怪物都会掉落，是打造与升级的常用素材。
- **强化系列材料**：来自世界 Boss 与亡灵系怪物，用于强化装备。
- **灵魂系列材料**：来自灵魂骑士等首领，用于灵魂主题装备。
- **光明系列材料**：来自纯净光灵等元素生物。
