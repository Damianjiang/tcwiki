# 数据统计查询

想知道自己玩了多久、挖了多少方块、服务器哪个世界最活跃，用这个查。

## 用法

在游戏内输入：

```
/plan
```

聊天框会返回一个网页地址。**用电脑浏览器打开**，能看到：

- 你和其他玩家的在线时长排名
- 各世界的方块/生物活动统计
- 服务器性能曲线（TPS、内存）

::: warning 注意
- 链接是临时的，过一段时间会失效，收到后尽快打开
- 手机浏览器可能排版错乱，建议用电脑看
:::

## 只想看谁在线？

不用开网页，直接 `/player`（别名 `/players`、`/online`），见 [服务器状态查询](/guide/status)。
