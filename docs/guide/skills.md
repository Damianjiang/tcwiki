# 技能奖励与战利品系统

::: tip 💡 系统简介
服务器内置 **RPG 技能系统**，玩家通过挖矿、钓鱼、打怪、农耕、附魔等原版行为升级技能等级，解锁属性、能力与稀有掉落。

**如何打开技能系统：** 输入主菜单指令 **`/cd`** 打开主菜单，在主菜单中找到 **技能** 并点击进入即可（无需经过 RPG 面板）。
:::

## 技能总览

服务器共启用 **11 种技能**，每种满级 100 级。被动能力在升级过程中依次解锁，主动法力能力在 6 级解锁，需消耗法力值释放。

| 技能 | 主要经验来源 | 代表能力 |
|------|--------------|----------|
| 农耕 | 收获成熟农作物 | 丰饶收获、自动补种、生长光环 |
| 伐木 | 砍伐原木与树叶 | 双倍原木、连锁伐树 |
| 采矿 | 挖掘各类矿石 | 双倍掉落、极速挖掘、硬化护甲 |
| 钓鱼 | 钓鱼（含宝藏与稀有/史诗池） | 双倍战利品、寻宝者、利钩 |
| 挖掘 | 铲除泥土/砂砾/黏土/沙 | 双倍掉落、范围挖掘 |
| 弓术 | 用弓/弩射杀生物 | 回收箭矢、穿透、蓄力射击 |
| 防御 | 承受并存活伤害 | 护盾、吸收护盾、怪物克星 |
| 战斗 | 近战击杀生物 | 招架、剑术大师、雷霆之刃 |
| 敏捷 | 跳跃/行走/疾跑/游泳/坠落 | 轻落、疾影、雷落 |
| 炼药 | 酿造与饮用药水 | 药水增益增强 |
| 附魔 | 附魔台/铁砧合成 | 经验转化、附魔增伤 |

> 每种技能的能力效果都可以在技能菜单中查看详细说明，无需背诵。

## 技能等级奖励系统

### 奖励说明

每提升技能等级，系统会自动发放对应奖励，分为**固定等级奖励**和**循环等级奖励**两种：

- **循环奖励** - 每固定等级间隔自动触发（如每 1 级、每 2 级）
- **固定奖励** - 仅在指定等级一次性触发（如 5 级、10 级专属奖励）

### 玩家可获得的全部奖励类型

**属性奖励**
自动提升人物基础属性，永久生效：
- 力量
- 生命
- 韧性
- 幸运
- 智慧
- 生命恢复

**指令奖励**
升级时自动执行服务器指令，例如：升级送点券、送称号、发放 buff。

**权限奖励**
达到指定技能等级自动解锁专属权限，降级会自动回收权限，无需手动操作。

**物品奖励**
升级自动发放自定义物品，背包满时物品会暂存，不会丢失。

## 自定义战利品掉落系统

### 掉落触发技能

服务器开启了自定义稀有掉落的技能：
- 钓鱼
- 挖掘
- 采矿
- 采集

### 战利品掉落机制

玩家进行对应技能行为时，有概率触发稀有池 / 史诗池掉落：
- **稀有掉落** - 普通稀有物资
- **史诗掉落** - 高阶稀有、专属道具、特殊物品

### 掉落加成规则

- 幸运属性越高，稀有 / 史诗掉落概率越高
- 部分钓鱼掉落仅在开阔水域生效（防挂机钓鱼）
- 自定义掉落可覆盖原版掉落，替换成服务器专属物资

### 战利品类型

服务器自定义掉落包含：
- 附魔随机等级装备、工具
- 带自定义名称、Lore、发光特效的专属物品
- 特殊药水效果物品
- 稀有资源、限定道具
- 掉落时自动提示获取消息

## 玩家小贴士

::: tip 💡 进阶建议
- 所有技能升级、属性、奖励记录**永久保存**，不会因下线或重启丢失
- **幸运属性**是提升稀有掉落的核心属性，建议优先提升
- 高阶战利品仅靠提升对应技能等级 + 幸运属性获取，无其他捷径
- 全部技能数据、解锁能力、奖励记录，均可在 `/cd` 主菜单的技能面板中一键查看
:::

::: warning ⚠️ 防挂机机制
部分钓鱼掉落**仅在开阔水域生效**，这是为了防止挂机钓鱼。请前往开阔水域手动钓鱼才能触发稀有掉落。
:::
