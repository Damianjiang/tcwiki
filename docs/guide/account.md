# 登录与注册

进服必须先注册，之后每次进服都要登录。

## 第一次进服：注册

```
/reg 密码 密码
```

两次密码必须一样。比如：

```
/reg Tc2024#abc Tc2024#abc
```

（示例只是格式，**别直接照抄**，自己换一个。）

注册成功后自动登录。

::: warning 密码丢了找不回来
服务器**没有自助找回密码**功能，忘了只能找服主重置。请务必记好。
:::

## 之后每次进服：登录

```
/l 你的密码
```

登录成功才能移动和使用指令。

## 改密码

登录状态下输入：

```
/changepassword 旧密码 新密码
```

## 指令对照

| 完整写法 | 简写 | 作用 |
|---|---|---|
| `/register <密码> <密码>` | `/reg` | 注册 |
| `/login <密码>` | `/l` | 登录 |
| `/changepassword <旧> <新>` | — | 改密码 |
