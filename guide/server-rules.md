# TCraft服务器规则

## 一、适用范围

本规则适用于 `xm.rainplay.cn`、`tcraft.pages.dev`、`tcwiki.pages.dev`、`tcwiki.github.io`、`*.tcraft.dpdns.org` 所有域名及子域名下全部 Minecraft Java Edition 服务器（官方服务器列表内所有群组服）。

**所有进入服务器的玩家，即默认同意本规则全部条款，无条件服从管理判定。**

## 二、核心总纲（最重要）

1. **本服全面开放所有作弊功能** 本服**不限制任何外挂、作弊客户端、作弊模组、作弊功能**。 透视、飞行、加速、杀戮光环、自瞄、穿墙、距离修改、矿透、自动挖矿、自动钓鱼、连点、物品作弊、实体追踪、背包修改等**全部作弊行为、作弊模块均完全允许、不予封禁、不予处罚**。
    
2. **唯一红线：禁止损害服务器与公共环境** 所有违规判定**与是否作弊无关**。 仅以下行为属于违规：**恶意熊破坏、制造卡服机器、触发服务器卡顿 / 过载 / 看门狗崩溃、私自建造高危毁服机械、违规堆叠生物、滥用机制拖垮服务器性能**。
    
3. 管理判定原则 一切以**服务器性能数据、卡顿日志、崩溃记录、建筑破坏证据**为准，不针对个人作弊行为追责，只针对毁服、卡服、熊行为追责。
    

## 三、严格禁止事项（违者直接处罚・附精准处罚结果）

> 所有本条目行为**无容忍、无需警告、直接执行处罚**

1. 🚫 **恶意熊破坏、恶意炸服、大面积毁图** 处罚：**永久封禁账号 + 清除全部违规建筑数据**
    
2. 🚫 **任何行为触发服务器看门狗崩溃、强制关服** 处罚：**永久踢出并拉黑服务器，永久封禁**
    
3. 🚫 **人为操作、机械装置造成服务器大范围、持续性卡顿、TPS 暴跌** 处罚：**服务器小黑屋封禁 7 天，强制清理卡服设备**
    
4. 🚫 **末地维度种植大量蘑菇、堆载蘑菇区块** 处罚：**封禁 3 天 + 清空违规区块**
    
5. 🚫 **末地祭坛范围内制作、部署杀凋机、高频凋灵刷新装置** 处罚：**封禁 7 天 + 拆除违规机器**
    
6. 🚫 **刷怪笼内部 / 周边养鸡、大量堆叠家禽造成实体堆积** 处罚：**清空实体 + 封禁 1 天**
    
7. 🚫 **大规模批量养殖生物、超高实体堆叠（牛马猪鸡猫等）造成区块过载** 处罚：**全员实体清空 + 违规玩家封禁 3 天**
    
8. 🚫 **远距离搬运、定点批量放置蜂巢 / 蜂箱，造成区块实体常驻过载** 处罚：**拆除装置 + 封禁 1 天**
    
9. 🚫 **制作、运行各类卡服机、禁人书、禁人塔、区块锁死装置** 处罚：**永久封禁 + 全域清除违规设备**
    
10. 🚫 **对拉杆、按钮、压力板进行极速连点、高频右键刷屏操作恶意卡服** 处罚：**禁言 3 天 + 情节严重封禁 7 天**
    
11. 🚫 **传播、教学、分享本服各类卡服、崩服、毁服机制** 处罚：**封禁 7 天，屡犯永久封禁**
    
12. 🚫 **恶意举报、诬告正常玩家、恶意干扰管理工作** 处罚：**禁言 7 天**
    
13. 🚫 **小号入驻、小号绕封、小号违规顶号** 处罚：**大小号同步永久封禁**
    
14. 🚫 **宣传外服、引流外服、搬运本服素材做外服宣传** 处罚：**永久禁言 + 严重者封禁**
    如果此玩家不改，管理可加量

## 四、高危设备 / 机械强制报备制度（不报备即违规）

以下**大型高能、高负载、可毁服机器**，**建造、开机、试运行前必须私信管理员报备**，登记坐标、用途、运行时长，未经报备私自运行一律按卡服违规处罚：

1. 飞行器轰炸机、高速弹射飞行器、世界吞噬机（世吞）
    
2. 各类大型轨道炮、TNT 大炮、连发炮组、远程爆破装置
    
3. 大型高频红石阵列、大规模脉冲红石设备
    
4. 大型全自动刷怪、刷物、掉落物堆积机器
    

✅ **报备通过：可合法使用** ❌ **私自建造运行：直接封禁 7 天 + 强制拆除设备** ⚠️ 报备设备使用中一旦出现卡顿、掉 TPS、服务器负载异常，需立刻停机，拒不停机直接顶格处罚。

## 五、服务器游玩注意事项（常规底线）

1. 禁止长时间挂机占用地狱门加载器、恶意常驻区块加载造成服务器持续负载。
    
2. 低 Y 轴底层禁止利用盔甲架挂机、卡死挂机线程；底层挂机必须做好防蝙蝠、防实体堆积措施，违规造成卡顿按卡服条例处罚。
    
3. 禁止滥用高频指令、重复指令刷屏拖垮服务器主线程。
    
4. 禁止散播消极言论、煽动退服、抹黑服务器、挑动玩家对立。
    
5. 尊重管理团队执法，禁止挑衅、对线、辱骂管理员。
    

## 六、分级处罚标准（统一固定、公开透明）

1. **轻度违规（无意小型卡区块、轻微违规摆放）** 处罚：口头警告、当场整改、限时拆除
    
2. **中度违规（实体堆积、违规小型机器、恶意刷屏）** 处罚：禁言 1–3 天、封禁 1–3 天、清理违规数据
    
3. **重度违规（私自部署高危机器、造成服务器卡顿 TPS 暴跌）** 处罚：**固定小黑屋 7 天**、强制拆除全部违规设备
    
4. **严重违规（触发看门狗崩服、恶意大规模熊毁、传播毁服教程、屡教不改）** 处罚：**永久封禁、永久拉黑、清除全部建筑与数据**
    

## 七、通用附则

1. 本服**作弊完全自由**，所有个人作弊、客户端作弊、模组作弊不违规、不追责、不限制。
    
2. 所有规则未列明，但**实质造成服务器卡顿、负载异常、区块崩溃、公共损失**的行为，管理团队拥有最终判定权，可依规处罚。
    
3. 本规则可随时更新增补，更新后即时生效，无需单独通知。
    
4. 所有游玩行为默认视为已知晓并同意全部规则，不接受 "不知情" 辩解。
    
5. 本规则为服务器唯一最高准则，所有群规、临时规定均以此文件为准。
    

## 八、最终说明

本服主打**高自由、宽松游玩环境**，放开全部作弊权限，保障玩家娱乐体验； 仅严控**毁服、卡服、熊破坏**行为，维护服务器稳定运行，保障全体玩家正常游玩。 感谢各位玩家配合，共创自由优质的游玩社区！
