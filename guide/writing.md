# 写作指南

## Markdown 基础

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 列表

- 无序列表项 1
- 无序列表项 2
- 无序列表项 3

1. 有序列表项 1
2. 有序列表项 2
3. 有序列表项 3

### 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](https://example.com/image.jpg)
```

## 代码块

```javascript
function hello() {
  console.log('Hello, World!');
}
```

## 表情符号

支持 Emoji 表情：:smile: :fire: :star: :rocket:
