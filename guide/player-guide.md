# 玩家百科

## 一、皮肤系统

### 玩家常用指令（必记）

| 指令 | 说明 |
|------|------|
| `/skin` | 打开皮肤面板（GUI） |
| `/skin <正版ID>` | 套用正版玩家皮肤（例：`/skin Notch`） |
| `/skin url "图片链接" [classic/slim]` | 上传自定义皮肤（PNG 64×64）<br>`classic`：Steve 粗手臂；`slim`：Alex 细手臂 |
| `/skin update` | 刷新当前皮肤 |
| `/skin clear` | 清除皮肤，恢复默认 |
| `/skin edit` | 在线编辑当前皮肤（生成链接后上传） |

### 自定义皮肤上传步骤

1. 准备 64×64 PNG 皮肤图
2. 访问 skinsrestorer.net/upload 上传，生成指令
3. 复制 `/skin url "链接"` 进游戏发送，立即生效

### 常见问题

**Q：皮肤不显示？**
A：检查权限 `skinsrestorer.player`，确认图片链接有效、格式为 PNG。

**Q：换肤没反应？**
A：用 `/skin update` 刷新，或检查网络/缓存。

## 二、传送系统

### 传送指令

| 指令 | 说明 |
|------|------|
| `/tpa <玩家名称>` | 向玩家发送传送请求 |
| `/tphere <玩家名称>` | 请求玩家传送到你身边 |
| `/tpaccept` | 接受传送请求（你可以点击聊天框里的 [接受] 来直接接受） |
| `/tpdeny` | 拒绝传送请求（你可以点击聊天框里的 [拒绝] 来直接拒绝，点击聊天框中的 [拒绝并拉黑] 将拒绝请求并且拉黑该玩家） |
| `/denys [add/remove] [玩家名称]` | 管理黑名单，列出玩家的黑名单列表 |

### 家指令

| 指令 | 说明 |
|------|------|
| `/home <家>` | 传送到家 |
| `/homes` | 列出你设置的家 |
| `/sethome <家>` | 设置家 |
| `/setdefaulthome <家>` | 设置默认的家 |
| `/delhome <家>` | 删除家 |

### 传送点指令

| 指令 | 说明 |
|------|------|
| `/warp <传送点>` | 传送到传送点 |
| `/setwarp <传送点>` | 设置传送点 |
| `/delwarp <传送点>` | 删除传送点 |

### 主城指令

| 指令 | 说明 |
|------|------|
| `/spawn` | 传送到主城 |
| `/setspawn` | 设置主城 |
| `/delspawn` | 删除主城 |

### 其他指令

| 指令 | 说明 |
|------|------|
| `/back` | 传送到上一次的位置 |
| `/rtp` | 随机传送 |

### 使用说明

#### 传送请求
- 使用 `/tpa <玩家名>` 请求传送到对方身边
- 使用 `/tphere <玩家名>` 请求对方传送到你身边
- 对方会收到聊天提示，可以点击 [接受] 或 [拒绝]
- 你也可以使用 `/tpaccept` 接受或 `/tpdeny` 拒绝

#### 黑名单管理
- 使用 `/denys add <玩家名>` 添加玩家到黑名单
- 使用 `/denys remove <玩家名>` 从黑名单移除玩家
- 使用 `/denys` 查看黑名单列表
- 被拉黑的玩家无法向你发送传送请求

#### 回家系统
- 你可以设置多个家的位置
- 使用 `/homes` 查看所有已设置的家
- 使用 `/setdefaulthome <家>` 设置默认家（输入 `/home` 时默认传送到这里）

#### 回退功能
- `/back` 可以传送到上一次死亡或传送前的位置
- 方便你回到刚才的地方继续游戏

#### 随机传送
- `/rtp` 可以随机传送到地图的任意位置
- 适合探索新区域或寻找资源

## 三、技能奖励与战利品系统

### 系统简介

**Skill** 是服务器 RPG 技能插件，玩家通过挖矿、钓鱼、打怪、农耕、附魔等原版行为升级技能等级。

升级技能可获得：

- **人物属性提升** - 血量、力量、幸运、韧性等
- **解锁被动技能、主动魔力技能**
- **等级专属奖励、权限、物品**
- **稀有自定义战利品掉落**

所有功能均可在游戏内输入 `/skills` 打开面板查看。

### 技能等级奖励系统

#### 奖励说明

每提升技能等级，系统会自动发放对应奖励，分为**固定等级奖励**和**循环等级奖励**两种：

- **循环奖励** - 每固定等级间隔自动触发（如每 1 级、每 2 级）
- **固定奖励** - 仅在指定等级一次性触发（如 5 级、10 级专属奖励）

#### 玩家可获得的全部奖励类型

**属性奖励**
自动提升人物基础属性，永久生效：
- 力量
- 生命
- 韧性
- 幸运
- 智慧
- 生命恢复

**指令奖励**
升级时自动执行服务器指令，例如：升级送点券、送称号、发放 buff。

**权限奖励**
达到指定技能等级自动解锁专属权限，降级会自动回收权限，无需手动操作。

**物品奖励**
升级自动发放自定义物品，背包满时物品会暂存，不会丢失。

### 自定义战利品掉落系统

#### 掉落触发技能

服务器开启了自定义稀有掉落的技能：
- 钓鱼
- 挖掘
- 采矿
- 采集

#### 战利品掉落机制

玩家进行对应技能行为时，有概率触发稀有池 / 史诗池掉落：
- **稀有掉落** - 普通稀有物资
- **史诗掉落** - 高阶稀有、专属道具、特殊物品

#### 掉落加成规则

- 幸运属性越高，稀有 / 史诗掉落概率越高
- 部分钓鱼掉落仅在开阔水域生效（防挂机钓鱼）
- 自定义掉落可覆盖原版掉落，替换成服务器专属物资

#### 战利品类型

服务器自定义掉落包含：
- 附魔随机等级装备、工具
- 带自定义名称、Lore、发光特效的专属物品
- 特殊药水效果物品
- 稀有资源、限定道具
- 掉落时自动提示获取消息

### 玩家小贴士

1. 所有技能升级、属性、奖励记录永久保存
2. 幸运属性是提升稀有掉落的核心属性
3. 高阶战利品仅靠提升对应技能等级 + 幸运属性获取
4. 全部技能数据、解锁能力、奖励记录，均可在 `/skills` 面板一键查看
