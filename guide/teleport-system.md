# 玩家百科 - 传送系统

## 传送指令

| 指令 | 说明 |
|------|------|
| `/tpa <玩家名称>` | 向玩家发送传送请求 |
| `/tphere <玩家名称>` | 请求玩家传送到你身边 |
| `/tpaccept` | 接受传送请求（你可以点击聊天框里的 [接受] 来直接接受） |
| `/tpdeny` | 拒绝传送请求（你可以点击聊天框里的 [拒绝] 来直接拒绝，点击聊天框中的 [拒绝并拉黑] 将拒绝请求并且拉黑该玩家） |
| `/denys [add/remove] [玩家名称]` | 管理黑名单，列出玩家的黑名单列表 |

## 使用说明

### 传送请求
- 使用 `/tpa <玩家名>` 请求传送到对方身边
- 使用 `/tphere <玩家名>` 请求对方传送到你身边
- 对方会收到聊天提示，可以点击 [接受] 或 [拒绝]
- 你也可以使用 `/tpaccept` 接受或 `/tpdeny` 拒绝

### 黑名单管理
- 使用 `/denys add <玩家名>` 添加玩家到黑名单
- 使用 `/denys remove <玩家名>` 从黑名单移除玩家
- 使用 `/denys` 查看黑名单列表
- 被拉黑的玩家无法向你发送传送请求

### 回家系统
- 你可以设置多个家的位置
- 使用 `/homes` 查看所有已设置的家
- 使用 `/setdefaulthome <家>` 设置默认家（输入 `/home` 时默认传送到这里）

### 回退功能
- `/back` 可以传送到上一次死亡或传送前的位置
- 方便你回到刚才的地方继续游戏

### 随机传送
- `/rtp` 可以随机传送到地图的任意位置
- 适合探索新区域或寻找资源
