# 快速开始

## 本地预览

### 方法一：使用 Node.js 工具

安装 docsify-cli：

```bash
npm i docsify-cli -g
```

启动本地服务：

```bash
docsify serve .
```

访问 `http://localhost:3000`

### 方法二：直接打开

直接用浏览器打开 `index.html` 即可预览（部分插件可能需要服务器环境）。

## 文档编写

在根目录创建 `.md` 文件，在 `_sidebar.md` 中添加链接即可。
