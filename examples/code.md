# 代码示例

## JavaScript

```javascript
// 一个简单的函数
function greet(name) {
  const message = `Hello, ${name}!`;
  console.log(message);
  return message;
}

// 调用函数
greet('World');
```

## Python

```python
def greet(name):
    """一个简单的问候函数"""
    message = f"Hello, {name}!"
    print(message)
    return message

# 调用函数
greet("World")
```
